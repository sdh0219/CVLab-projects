# AI应急指挥舱真实数据版运行说明

## 数据说明

真实公开数据放在 `data_package/`：

- `osm_chengdu_*.json`：OpenStreetMap Overpass API 抓取的成都医院、消防站、道路、候选避难场所点位。
- `open_meteo_chengdu_current.json`：Open-Meteo 当前气象数据。
- `processed/`：清洗后的 JSON/CSV 数据。
- `sources.md`：数据来源和不可公开字段说明。

库存数量、队伍人数、避难场所容量、实时转移人数、受灾人口等字段没有稳定公开接口，项目中不编造数值，前端显示为“未公开”。

## 后端运行

```powershell
cd backend
pip install -r requirements.txt
python -m app.data.import_real_data
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

## 前端运行

```powershell
cd frontend
npm install
npm run dev -- --host 127.0.0.1 --port 3000
```

浏览器打开：

```text
http://127.0.0.1:3000
```
