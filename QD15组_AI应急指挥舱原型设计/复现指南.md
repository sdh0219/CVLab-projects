> **这份指南写给完全没有编程经验的人。** 只要跟着步骤操作，不需要理解代码就能完成复现。

> **最快路径**：安装 Python + Node.js → 双击 `源码\一键运行.bat` → 浏览器打开大屏。全程约 20 分钟。

## 零、这个项目是做什么的

这是一个灾害应急指挥的大屏可视化系统。用真实公开数据（地震、洪水等灾害数据），在网页大屏上展示灾害分布、救援资源、实时态势等信息。

项目是前后端分离架构：
- **后端**：Python FastAPI 提供 API 接口（用 SQLite 数据库，无需安装数据库软件）
- **前端**：Vue3 大屏界面（用 ECharts 图表 + Leaflet 地图）

**你需要准备：**

- 一台 Windows 电脑
- 能上网的网络（安装依赖时需要下载约 700 MB）
- 预计耗时：**20 分钟**（首次安装），再次启动只需 30 秒
- **不需要** Redis 数据库（系统有容错处理）
- **不需要** OpenAI API key（大屏可正常显示，仅 AI 决策功能不可用）
- **不需要** MySQL/PostgreSQL（用内置 SQLite）

## 一、安装基础环境

本项目需要两个工具：Python（后端）和 Node.js（前端）。

### 1.1 安装 Python

1. 访问 https://www.python.org/downloads/
2. 下载 Python 3.10+
3. 双击安装包，**勾选底部 "Add Python to PATH"**，点击 "Install Now"
4. 验证：按 `Win + R` → 输入 `cmd` → 输入 `python --version` → 显示版本号 = 成功 ✓

### 1.2 安装 Node.js

1. 访问 https://nodejs.org/
2. 下载 **LTS 版本**（按钮上写 "LTS" 的那个）
3. 双击安装，一路点 "Next"，最后 "Install"，完成
4. 验证：在 cmd 中输入 `node --version` → 显示版本号 = 成功 ✓

## 三、一键运行（推荐零基础者使用）

### 3.1 运行

1. 进入项目的 **`源码`** 文件夹
2. 找到 **`一键运行.bat`**
3. **双击它**

### 3.2 等待自动完成

脚本会自动：
1. 创建后端虚拟环境并安装依赖（约 2 分钟，仅首次）
2. 导入数据（约 10 秒）
3. 安装前端依赖（约 3 分钟，仅首次）
4. 在两个新窗口中启动后端和前端

### 3.3 打开大屏

等待两个弹出窗口分别显示后端和前端"running"后：

1. 打开浏览器（推荐 Chrome）
2. 访问：**http://localhost:5173**
3. 看到 AI 应急指挥舱大屏 = 成功 ✓

### 3.4 关闭服务

关闭两个弹出的黑色窗口即可。

## 四、分步运行（想了解每步做了什么）

### 4.1 后端

打开 cmd，进入后端目录：

```
cd /d D:\你的路径\15组_AI应急指挥舱原型设计\源码\backend
```

创建虚拟环境并安装依赖：

```
python -m venv .venv
".venv\Scripts\python.exe" -m pip install -r requirements.txt
```

导入数据：

```
".venv\Scripts\python.exe" import_real_data.py
```

启动后端：

```
".venv\Scripts\python.exe" -m uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

后端启动后，API 文档在 http://localhost:8000/docs

### 4.2 前端

**新开一个 cmd 窗口**，进入前端目录：

```
cd /d D:\你的路径\15组_AI应急指挥舱原型设计\源码\frontend
```

安装依赖并启动：

```
npm install
npm run dev
```

前端启动后，访问 http://localhost:5173

> **注意**：后端和前端需要同时运行（两个窗口都不能关）。先启动后端，再启动前端。

## 六、遇到问题怎么办

### 报错对照表

| 报错信息 | 原因 | 解决方案 |
|---|---|---|
| `'python' 不是内部或外部命令` | Python 未安装或未加入 PATH | 重新安装 Python，勾选 "Add Python to PATH" |
| `'node' 不是内部或外部命令` | Node.js 未安装 | 安装 Node.js LTS 版本 |
| `npm install` 很慢或失败 | 网络问题 | 用国内镜像：`npm config set registry https://registry.npmmirror.com` |
| `pip install` 很慢 | 网络问题 | 加镜像：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple` |
| `ModuleNotFoundError` | 依赖未装全 | 重新双击 `一键运行.bat`，或手动执行 `pip install -r requirements.txt` |
| 前端访问 5173 端口白屏 | 后端未启动 | 检查后端窗口是否在运行，先启动后端再启动前端 |
| `Port 5173 already in use` | 5173 端口被占用 | 关闭其他可能占用该端口的程序，或修改 `vite.config.ts` 中的端口 |
| `Port 8000 already in use` | 8000 端口被占用 | 关闭其他可能占用该端口的程序 |
| 前端报 `Network Error` | 后端未启动或跨域问题 | 确保后端在 8000 端口运行 |

### 常见问题

**Q: 不装 Redis 能用吗？**
A: 能。系统有容错处理，Redis 不可用时缓存功能降级，大屏正常显示。

**Q: 不配 OpenAI key 能用吗？**
A: 能。大屏所有数据展示功能正常，只有"AI 决策建议"功能不可用。

**Q: 两个窗口可以关吗？**
A: 不能。后端和前端窗口分别提供 API 和页面，关了就停止服务了。关闭窗口 = 停止运行。

**Q: 下次运行还需要重新安装吗？**
A: 不需要。依赖只安装一次，下次双击 `一键运行.bat` 会直接启动。

**Q: 我想让别人也能访问怎么办？**
A: 后端已经绑定 `0.0.0.0:8000`，同一局域网内其他设备可通过你的 IP 访问。前端需要额外配置。

### 技术栈

- **后端**：FastAPI + SQLAlchemy + Pydantic + Redis（可选）+ OpenAI（可选）
- **前端**：Vue3 + Vite + Element Plus + ECharts + Leaflet
- **数据库**：SQLite（内置，无需安装）
- **大屏展示**：ECharts 图表 + Leaflet 地图

### 降级说明

| 组件 | 是否必需 | 不装的影响 |
|---|---|---|
| Python + Node.js | 必需 | 无法运行 |
| SQLite | 必需（但内置） | 无需额外安装 |
| Redis | **可选** | 缓存功能降级，大屏正常 |
| OpenAI API key | **可选** | AI 决策功能不可用，大屏正常 |
| MySQL/PostgreSQL | **不需要** | 项目用 SQLite |

> 如复现中遇到问题，可对照 `源码/backend/README.md` 或 `源码/frontend/README.md` 排查。
