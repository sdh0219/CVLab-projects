# QD09 · 个性化地震预警信息自动生成系统 · 零基础复现与使用指南

> 本指南面向零基础同学。跟着"复现手册"一步步做，就能把项目跑起来；再看"用户使用手册"理解它是什么、怎么用。
>
> **项目一句话**：地震发生后，不同人群需要的预警信息是不一样的——本项目根据用户画像（所在地、职业、关注点），自动生成"个性化"的地震预警文案，并在网页上展示。

# 第一部分 · 复现手册

## 1.1 你需要准备什么

| 需要的东西 | 说明 |
|---|---|
| Windows 电脑 | Windows 10/11，64 位 |
| Python 3.10+ | 安装见 1.2 |
| VS Code（推荐） | 安装见 1.3 |

地震事件数据已包含在 `数据集/` 中（中国地震台网 CEIC 历史地震目录），**默认无需联网**；联网时还可以用爬虫拉取最新地震。

## 1.2 安装 Python

1. 访问 **https://www.python.org/downloads/** ，点黄色 **Download Python 3.x.x**
2. 双击安装包，**务必勾选 "Add python.exe to PATH"**，点 Install Now
3. 验证：`Win + R` → `cmd` 回车 → 输入 `python --version`

## 1.3 安装 VS Code

访问 **https://code.visualstudio.com/** 下载安装。

## 1.4 下载本项目

项目结构：

```
QD09组_个性化地震预警信息自动生成系统/
├── 源码/
│   ├── app.py               ← 网页服务主程序（先跑这个）
│   ├── main.py              ← 数据处理脚本
│   ├── code/                ← 核心业务逻辑
│   │   ├── warning_generator.py  ← 预警文案生成
│   │   ├── user_profile.py       ← 用户画像
│   │   ├── warning_rules.py      ← 预警规则
│   │   └── visualization.py      ← 图表生成
│   ├── crawler/             ← 地震数据采集（联网时用）
│   ├── templates/           ← 网页模板（HTML）
│   └── static/              ← 网页样式与图片
├── 数据集/
│   ├── raw_data/            ← 地震原始数据
│   └── processed_data/      ← 清洗后的事件数据
└── 文档/                    ← 技术方案与报告
```

放到电脑上，例如 `D:\projects\QD09组_...`。

## 1.5 安装依赖

1. 打开 `源码` 文件夹，地址栏输入 `cmd` 回车
2. 创建并激活虚拟环境：

```
python -m venv venv
venv\Scripts\activate
```

3. 安装依赖：

```
pip install -r requirements.txt
```

> 国内网络慢可先执行 `pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple`。

## 1.6 启动网页服务

执行：

```
python app.py
```

看到 `Running on http://127.0.0.1:5000` 即启动成功。

## 1.7 打开系统

1. 打开浏览器，访问 **http://127.0.0.1:5000**
2. 看到系统首页（地震预警信息自动生成系统）即成功

**预期界面**：首页展示最近地震事件列表与预警信息；可通过页面切换查看用户画像、个性化预警、统计分析等页面。

## 1.8 复现完成

跑通 1.6-1.7 即复现完成。下面看使用手册。

# 第二部分 · 用户使用手册

## 2.1 这个项目是做什么的

地震预警信息通常"一刀切"：所有人都收到同样的话。但实际需求差异很大——居民想知道"要不要跑、往哪跑"，学校想知道"要不要停课"，医院想知道"伤员会不会增加"。

本项目根据**用户画像**（所在地区、身份角色、关注点）自动生成不同版本的预警文案，实现"千人千面"的预警：

```
地震事件数据（时间/地点/震级/深度）
        │  数据清洗与事件筛选
        ▼
   地震事件库
        │  用户画像（地区 / 角色 / 关注点）匹配规则
        ▼
   个性化预警规则引擎
        │
        ▼
   差异化预警文案（普通居民版 / 学校版 / 医院版 / 应急人员版…）
        │
        ▼
   Web 网页展示 + 统计图表
```

## 2.2 输入与输出

**输入**：
- `数据集/raw_data/` —— 中国地震台网（CEIC）历史地震目录原始数据
- 用户画像配置（页面中选择或代码中定义）

**输出**：
| 输出 | 说明 |
|---|---|
| 预警信息列表 | 每个地震事件对应的预警文案（含位置、震级、影响范围） |
| 个性化版本 | 不同角色的差异化文案 |
| 统计图表 | 地震分布、预警覆盖情况可视化 |
| Web 页面 | 交互式浏览（首页 / 预警详情 / 画像管理 / 统计） |

## 2.3 网页功能说明

| 功能 | 操作 | 说明 |
|---|---|---|
| 查看最近地震 | 打开首页 | 地震事件列表与最新预警 |
| 查看预警详情 | 点击某条地震 | 该事件的完整预警文案与地图/图表 |
| 切换用户角色 | 页面中的角色选项 | 看不同角色收到的差异化预警 |
| 统计分析 | 点击"统计"页 | 地震频次、预警覆盖等图表 |
| 刷新最新数据（联网） | 运行 crawler 脚本 | 从 CEIC/USGS 拉取最新地震 |

## 2.4 命令行功能（可选）

| 命令 | 作用 |
|---|---|
| `python app.py` | 启动网页服务（主入口） |
| `python main.py` | 手动重新处理数据 |
| `python -m crawler.update_earthquake_data` | 联网更新地震数据（需网络） |

## 2.5 常见问题

| 问题 | 原因与解决 |
|---|---|
| 浏览器打不开 | 确认命令行显示 `Running on http://127.0.0.1:5000`；端口被占则改 `python app.py` 前的端口配置 |
| 预警信息为空 | 确认 `数据集/` 存在且 `main.py` 已处理过数据（默认已处理） |
| 想要最新地震 | 联网后运行 crawler 更新脚本再刷新页面 |
