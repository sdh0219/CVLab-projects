## 2. 各模块作用说明

### 数据采集层（crawler/）

| 模块 | 文件 | 作用 |
|------|------|------|
| CEIC 采集 | `fetch_ceic.py` | 尝试采集中国地震台网公开目录 |
| USGS 采集 | `fetch_usgs.py` | 从 USGS FDSN 接口采集真实地震事件 |
| 更新入口 | `update_earthquake_data.py` | 统一调度采集、去重、保存、记录日志 |
| 工具函数 | `crawler_utils.py` | HTTP 请求、SHA256 校验、经纬度计算等 |

### 核心处理层（code/）

| 模块 | 文件 | 作用 |
|------|------|------|
| 数据加载 | `data_loader.py` | 从 CSV 读取真实地震事件数据 |
| 数据清洗 | `data_cleaner.py` | 时间格式化、数值转换、去重、缺失值处理 |
| 用户画像 | `user_profile.py` | 根据用户身份和年龄生成用户画像标签 |
| 预警规则 | `warning_rules.py` | 地震演示风险等级、行动建议、Haversine 距离计算 |
| 预警生成 | `warning_generator.py` | 综合事件、画像、规则生成个性化地震应急提醒 |
| 数据可视化 | `visualization.py` | 生成地震统计图表（震级分布、深度分布、时间趋势、地理散点） |

### 展示层（templates/ + static/）

| 组件 | 文件 | 作用 |
|------|------|------|
| 首页 | `templates/index.html` | 地震事件选择 + 输入表单 + 手机预警模拟 |
| 统计页 | `templates/dashboard.html` | 真实地震数据统计面板 |
| 样式 | `static/css/style.css` | 页面样式控制 |
| 手机图 | `static/images/phone_normal.png` | 正常手机锁屏图片 |
| 手机图 | `static/images/phone_blur.png` | 预警状态高斯模糊图片 |
| 统计图 | `static/charts/*.png` | 四张地震统计图表 |

### 服务层

| 组件 | 文件 | 作用 |
|------|------|------|
| Web 入口 | `app.py` | Flask 应用，处理路由和请求 |
| 数据处理入口 | `main.py` | 读取真实地震数据，清洗，生成统计图 |

## 3. 数据流转说明

### 数据采集流程

```
USGS FDSN API（HTTP GET）→ GeoJSON 响应
        │
        ▼
    保存原始 GeoJSON 快照（source_snapshot/）
        │
        ▼
    解析 GeoJSON → 提取事件字段
        │
        ▼
    保存原始 CSV（earthquake_usgs_raw_*.csv）
        │
        ▼
    去重（按时间+经纬度+震级）
        │
        ▼
    保存处理后数据（earthquake_events_processed.csv）
        │
        ▼
    记录 source_metadata.json + crawl_log.txt
```

### 用户交互流程

```
用户访问 http://127.0.0.1:5000
        │
        ▼
    Flask 加载真实地震事件列表 → 渲染 index.html
        │
        ▼
    用户选择地震事件 → 前端获取事件详情（/get_event_detail）
        │
        ▼
    用户填写表单 → 点击"生成预警信息"
        │
        ▼
    fetch POST /generate
        │
        ▼
    app.py 调用 generate_earthquake_warning()
        │
        ▼
    返回 JSON（事件信息、画像、需求、等级、建议、距离信息、文本）
        │
        ▼
    前端 JS：切换手机模糊图 → 弹出预警通知卡片
```

## 4. 页面交互流程

### 首页交互

1. **初始状态**：页面加载后，左侧显示地震事件选择 + 输入表单，右侧显示手机锁屏图片。
2. **选择地震事件**：下拉框默认选中最新事件，自动显示事件详情卡片。
3. **填写信息**：选择人员身份、年龄、位置、行动能力。
4. **一键定位**：使用浏览器 Geolocation API 获取当前位置经纬度。
5. **生成预警**：点击"生成预警信息"，前端发送 POST 请求到 `/generate`。
6. **弹窗展示**：显示地震事件、用户画像、重点需求、演示风险等级、距离信息、行动建议、完整文本和免责声明。

### 数据统计页面交互

1. **统计概览**：真实地震记录数、数据来源、最大震级、平均深度、最新数据时间。
2. **四张统计图**：震级分布、深度分布、时间趋势、地理散点分布。
3. **最近 20 条真实地震事件表格**：发震时间、震级、深度、纬度、经度、参考位置、来源。
4. **免责声明**：页面顶部注明数据来源于公开地震目录。
