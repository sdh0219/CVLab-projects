## 零、这个项目是做什么的

本项目模拟灾害场景下的求救信息处理。当灾害发生时，社交平台上会出现大量求救信息
（比如"郑州京广路隧道被淹，水深2米，我们一辆车4个人出不来，求救船只"），
人工逐条阅读太慢。本项目用 AI 自动完成两件事：

- **自动提取关键信息**：从一条求救文本里自动识别出**地点**、**人员**、**灾情**、**需求**
  四类关键信息（用 BERT 深度学习模型，测试集准确率 F1 = 0.95）
- **自动定位到地图上**：根据提取出的地点，自动查到经纬度，在地图上标出求救点位置，
  生成一份**交互式求救点分布仪表盘**（288 个求救点全部定位成功）

**一句话理解**：输入一堆灾害求救微博 → AI 自动整理成表格 + 画出求救点分布地图。

**你需要准备：**

- 一台 Windows 电脑（Mac/Linux 也可以，但下面步骤以 Windows 为例）
- 能上网的网络（安装依赖时需要，之后运行不需要）
- 预计耗时：**10 分钟**（已装好 Python）或 **20 分钟**（从零开始）

> **关于 GPU**：本项目内置了训练好的模型，**不需要 GPU，不需要训练**，普通电脑就能跑。
> 如果你想自己重新训练模型，有 NVIDIA 显卡会快很多（5-10 分钟），没显卡用 CPU 也行（30-60 分钟）。

## 一、安装 Python（已装可跳过）

### 1.1 下载 Python

1. 打开浏览器，访问：https://www.python.org/downloads/
2. 点击页面上黄色的 **"Download Python 3.x.x"** 按钮
3. 等待下载完成（文件约 25 MB）

### 1.2 安装 Python（关键步骤！）

1. 找到下载的安装包（通常在"下载"文件夹），**双击运行**
2. 安装界面打开后，你会看到两个大按钮和底部有一行小字
3. **先勾选底部 "Add Python to PATH"** ← 这一步非常重要！不勾选后面会报错
4. 然后点击 **"Install Now"**
5. 等待进度条走完（约 30 秒），点击 **"Close"** 关闭

### 1.3 验证安装成功

1. 按键盘 `Win + R`（同时按 Windows 键和 R 键），弹出"运行"窗口
2. 输入 `cmd`，按回车，会弹出一个黑色窗口
3. 在黑色窗口中输入以下命令，然后按回车：

   ```
   python --version
   ```

4. 如果显示 `Python 3.10.x`（或更高版本号），说明安装成功 ✓
5. 如果显示"不是内部或外部命令"，说明第 3 步的"Add to PATH"没勾选，请重新安装

## 四、分步运行（想了解每步做了什么）

如果你想自己手动操作，可以按以下步骤进行。所有命令在 **`源码`** 目录下执行。

### 4.1 打开命令行

1. 按 `Win + R`，输入 `cmd`，按回车
2. 用 `cd` 命令进入项目的源码目录（把路径换成你自己的实际路径）：

   ```
   cd /d D:\你的路径\12组_社交媒体求救信息自动提取与定位\源码
   ```

### 4.2 创建虚拟环境并安装依赖

```
python -m venv .venv
".venv\Scripts\python.exe" -m pip install --upgrade pip
```

**安装 PyTorch（CPU 版，推荐，不需要 GPU）：**

```
".venv\Scripts\python.exe" -m pip install torch --index-url https://download.pytorch.org/whl/cpu
```

> **如果有 NVIDIA 显卡想用 GPU 加速**（可选，仅训练需要，推理不需要）：
> 访问 https://pytorch.org/get-started/locally/ 选择对应 CUDA 版本，例如：
> `pip install torch --index-url https://download.pytorch.org/whl/cu121`

**安装其他依赖：**

```
".venv\Scripts\python.exe" -m pip install -r requirements.txt
```

> **什么是虚拟环境？** 就是一个独立的 Python 环境文件夹，装在这里的依赖不会影响你电脑上其他 Python 项目。

### 4.3 数据准备（生成地名库 + 数据集 + 标注）

```
".venv\Scripts\python.exe" -m src.geo.build_geo_dict
".venv\Scripts\python.exe" -m src.data.build_dataset
".venv\Scripts\python.exe" -m src.data.annotate
```

> 这三步会生成：212 条中国灾区地名库、288 条原始求救文本、BIO 标注的 train/dev/test 数据。
> 如果数据集已存在，这几步会覆盖重建（结果一致）。

### 4.4 评估模型（用已内置的检查点，复现 F1 = 0.95）

```
".venv\Scripts\python.exe" -m src.evaluate
```

> 这一步会加载 `outputs/checkpoints/bert_ner_best/` 里的训练好的模型，
> 在测试集上评估，输出 P/R/F1 指标，结果保存在 `outputs/reports/metrics.json`。

### 4.5 批量推理（288 条求救文本 → 结构化表格）

```
".venv\Scripts\python.exe" -m src.infer --batch
```

> 这一步会对 288 条原始求救文本逐条推理，提取地点/人员/灾情/需求，
> 进行地理编码查经纬度，最后导出 `数据集\processed\structured_results.csv`。

### 4.6 生成求救点分布仪表盘

```
".venv\Scripts\python.exe" -m src.visualize
```

> 生成 `outputs/maps/rescue_map.html`——一份交互式 HTML 仪表盘，
> 288 个求救点按真实经纬度标在地图上，支持搜索/筛选/点击定位。
> 首次运行前如缺少静态资源，先运行：`".venv\Scripts\python.exe" scripts\download_static.py`

### 4.7 单条文本推理（演示用）

```
".venv\Scripts\python.exe" -m src.infer --text "求助! 汶川映秀镇3楼塌了,有3个人,急需水,电话13900001234"
```

> 输入一条自定义求救文本，立即看到提取结果和定位。

### 4.8 完整训练（可选，已有检查点可跳过）

如果你想从头训练模型（而不是用内置的检查点）：

```
".venv\Scripts\python.exe" -m src.train                    # 用默认参数训练
".venv\Scripts\python.exe" -m src.train --epochs 5         # 只训 5 轮（快速测试）
".venv\Scripts\python.exe" -m src.train --no_crf           # 不用 CRF（消融实验）
```

## 六、遇到问题怎么办

### 报错对照表

| 报错信息 | 原因 | 解决方案 |
|---|---|---|
| `'python' 不是内部或外部命令` | Python 未安装或未加入 PATH | 重新安装 Python，务必勾选 "Add Python to PATH" |
| `ModuleNotFoundError: No module named 'torch'` | PyTorch 未安装 | 双击 `一键运行.bat` 重新运行，或手动执行：`pip install torch --index-url https://download.pytorch.org/whl/cpu` |
| `ModuleNotFoundError: No module named 'transformers'` | 依赖未装全 | 双击 `一键运行.bat` 重新运行，或手动执行：`pip install -r requirements.txt` |
| `OSError: ... bert-base-chinese 下载失败` | BERT 模型缺失 | 项目已内置模型在 `源码/models/`，检查文件夹是否完整；如缺失，运行 `python scripts/download_model.py` 从国内镜像重下 |
| `FileNotFoundError: ... bert_ner_best` | 模型检查点缺失 | 检查 `源码/outputs/checkpoints/bert_ner_best/pytorch_model.bin` 是否存在；如缺失需重新训练：`python -m src.train` |
| `FileNotFoundError: ... 数据集` | 数据路径不对 | 确保 `数据集/` 目录完整，没有移动或重命名；检查 `源码/src/config.py` 的 `DATA_DIR` 指向 `../数据集/` |
| `PermissionError` | 文件被占用 | 关闭所有打开的结果文件（如 Excel 正在打开 csv、浏览器正在打开 html），重新运行 |
| 窗口一闪就关了 | 运行出错 | 在 cmd 中手动进入 `源码` 目录，运行 `一键运行.bat` 看报错信息 |
| `RuntimeError: CUDA out of memory` | GPU 显存不足 | 用 CPU 版运行（默认就是 CPU 版）；或减少 batch size |
| 安装依赖卡住 / 超时 | 网络问题 | 使用国内镜像：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple` |
| `UnicodeDecodeError` | 中文路径编码问题 | 确保终端使用 UTF-8（`chcp 65001`），路径不要含特殊字符 |

### PyTorch 安装问题（最常见的障碍）

PyTorch 是本项目的核心依赖，安装时可能遇到以下问题：

**问题 1：默认安装的 PyTorch 太大（约 2.5GB）**

默认 `pip install torch` 会下载包含 CUDA 的 GPU 版本（约 2.5GB），下载慢且占空间。
如果你只是**运行推理**（不需要训练），用 CPU 版即可（约 200MB）：

```
pip install torch --index-url https://download.pytorch.org/whl/cpu
```

**问题 2：安装失败 / 下载超时**

使用国内 PyPI 镜像加速：

```
pip install torch --index-url https://download.pytorch.org/whl/cpu -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**问题 3：有 NVIDIA 显卡想用 GPU**

1. 先确认你的 CUDA 版本：在 cmd 输入 `nvidia-smi`，看右上角 CUDA Version
2. 访问 https://pytorch.org/get-started/locally/ 选择对应版本
3. 例如 CUDA 12.1：`pip install torch --index-url https://download.pytorch.org/whl/cu121`

> **提示**：本项目内置了训练好的模型，**推理不需要 GPU**，CPU 版 PyTorch 完全够用。

### BERT 模型问题

**问题：训练时报 `OSError: bert-base-chinese 下载失败`？**

本项目已内置 BERT 预训练模型在 `源码/models/AI-ModelScope/bert-base-chinese/`，正常情况不需要下载。
如果该文件夹缺失或损坏，用国内镜像重新下载：

```
".venv\Scripts\python.exe" scripts\download_model.py
```

或者设置 HuggingFace 国内镜像后重试：

```
set HF_ENDPOINT=https://hf-mirror.com
".venv\Scripts\python.exe" -m src.train
```

### 常见问题

**Q: 我可以不用命令行吗？**
A: 可以。双击 `一键运行.bat` 即可，不需要手动输入任何命令。

**Q: 第二次运行还需要重新安装吗？**
A: 不需要。虚拟环境和依赖只安装一次，之后每次运行会自动跳过安装步骤，直接运行推理。

**Q: 没有 GPU 能跑吗？**
A: 完全可以。本项目内置了训练好的模型，推理用 CPU 即可，约 1-2 分钟完成 288 条推理。
   只有自己训练模型时 GPU 才有明显优势。

**Q: 运行结果和指南里的数字不一样？**
A: 正常。推理结果受随机种子和数据精度影响，可能略有差异。核心结论
   （F1 约 0.95、288 条全部定位成功）不会变。

**Q: 地图底图不显示 / 是空白背景？**
A: 地图底图（街道瓦片）需要在线加载。断网时会降级为纯色背景，
   但所有标记、弹窗、筛选、定位功能完全离线可用。联网后刷新页面即可看到底图。

**Q: TensorBoard 提示 "TensorFlow installation not found"？**
A: 正常，不影响使用。我们用的是 PyTorch 不是 TensorFlow，这只是少了一些高级功能，
   SCALARS/HPARAMS/TEXT 这些我们用的面板都正常。

**Q: 想试一条自己的求救文本怎么办？**
A: 在 `源码` 目录下运行：
   `".venv\Scripts\python.exe" -m src.infer --text "你的求救文本"`
   会立即看到提取的地点/人员/灾情/需求和定位结果。

**Q: LLM 基线（通义千问）怎么跑？**

### 核心流程

整个项目是一条深度学习流水线，分 6 个阶段：

```
数据构建 → BIO 标注 → BERT+CRF 训练 → 评估 → 推理 → 地理编码 + 可视化
   │           │            │            │        │            │
   ▼           ▼            ▼            ▼        ▼            ▼
 288条原始   train/dev    模型权重     F1=0.95   CSV 表格    HTML 仪表盘
 求救文本    /test 划分   (已内置)     (已内置)   (288 条)    (288 点地图)
```

### 核心技术

- **模型**：BERT（bert-base-chinese）+ 线性层 + CRF（条件随机场）
- **任务**：序列标注（NER 命名实体识别），BIO 标注体系
- **4 类实体**：LOC（地点）、PER（人员）、DIS（灾情）、NEED（需求）
- **评估**：seqeval 严格实体级评估（类型 + 边界完全匹配才算对）
- **地理编码**：本地 212 条地名库（最长匹配）+ 高德/百度在线 API 回退
- **可视化**：Leaflet + MarkerCluster + jQuery（全部本地化，0 CDN 引用）
