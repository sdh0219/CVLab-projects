# 源码说明文档

## 主要目录

- `src/`：核心路径规划算法。
- `tools/`：数据处理、灾害映射、路网构建和可视化脚本。
- `national_disaster_platform/`：本地网页演示平台。
- `tests/`：基础测试。
- `configs/`：OSM灾害流水线配置。

## 运行方式

```powershell
python src\rescue_planner.py --data-dir ..\1_数据包\osm_sichuan_earthquake --output-dir ..\1_数据包\结果输出\osm_sichuan_earthquake
python src\rescue_planner.py --data-dir ..\1_数据包\osm_beijing_flood --output-dir ..\1_数据包\结果输出\osm_beijing_flood
python src\rescue_planner.py --data-dir ..\1_数据包\osm_shanghai_fire --output-dir ..\1_数据包\结果输出\osm_shanghai_fire
python national_disaster_platform\server.py
```
