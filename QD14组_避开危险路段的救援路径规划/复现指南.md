## 零、这个项目是做什么的

本项目模拟灾害场景下的救援路径规划。用真实地图道路数据和历史灾害资料，计算两种路径：

- **普通最短路径**：只看距离最短，但可能经过危险路段
- **安全路径**：绕开塌方/积水等危险路段，虽然距离更长但更安全

项目内置了两个真实历史灾害场景：
- **地震场景**：1679 年三河-平谷地震
- **洪水场景**：2012 年北京 7·21 特大暴雨

**你需要准备：**

- 一台 Windows 电脑（Mac/Linux 也可以，但下面步骤以 Windows 为例）
- 能上网的网络（安装依赖时需要）
- 预计耗时：**5 分钟**（如果你已装好 Python）或 **15 分钟**（从零开始）

## 一、安装 Python（已装可跳过）

### 1.1 下载 Python

1. 打开浏览器，访问：https://www.python.org/downloads/
2. 点击页面上黄色的 **"Download Python 3.x.x"** 按钮
3. 等待下载完成（文件约 25 MB）

### 1.2 安装 Python（关键步骤！）

1. 找到下载的安装包（通常在"下载"文件夹），**双击运行**
2. 安装界面打开后，你会看到两个大按钮和底部有一行小字
3. **先勾选底部 "Add Python to PATH"** ← 这一步非常重要！不勾选后面会报错
4. 然后点击 **"Install Now"**
5. 等待进度条走完（约 30 秒），点击 **"Close"** 关闭

### 1.3 验证安装成功

1. 按键盘 `Win + R`（同时按 Windows 键和 R 键），弹出"运行"窗口
2. 输入 `cmd`，按回车，会弹出一个黑色窗口
3. 在黑色窗口中输入以下命令，然后按回车：

   ```
   python --version
   ```

4. 如果显示 `Python 3.10.x`（或更高版本号），说明安装成功 ✓
5. 如果显示"不是内部或外部命令"，说明第 3 步的"Add to PATH"没勾选，请重新安装

## 四、分步运行（想了解每步做了什么）

如果你想自己手动操作，可以按以下步骤进行。

### 4.1 打开命令行

1. 按 `Win + R`，输入 `cmd`，按回车
2. 用 `cd` 命令进入项目的源码目录（把路径换成你自己的实际路径）：

   ```
   cd /d D:\你的路径\14组_避开危险路段的救援路径规划\源码
   ```

### 4.2 创建虚拟环境并安装依赖

```
python -m venv .venv
".venv\Scripts\python.exe" -m pip install "Pillow>=10.0"
```

> **什么是虚拟环境？** 就是一个独立的 Python 环境文件夹，装在这里的依赖不会影响你电脑上其他 Python 项目。

### 4.3 运行地震场景

```
".venv\Scripts\python.exe" "src\rescue_planner.py" --data-dir "..\数据集\amap_earthquake" --output-dir "..\数据集\结果输出\amap_earthquake"
```

### 4.4 运行洪水场景

```
".venv\Scripts\python.exe" "src\rescue_planner.py" --data-dir "..\数据集\amap_flood" --output-dir "..\数据集\结果输出\amap_flood"
```

## 六、遇到问题怎么办

### 报错对照表

| 报错信息 | 原因 | 解决方案 |
|---|---|---|
| `'python' 不是内部或外部命令` | Python 未安装或未加入 PATH | 重新安装 Python，务必勾选 "Add Python to PATH" |
| `ModuleNotFoundError: No module named 'PIL'` | Pillow 未安装 | 双击 `一键运行.bat` 重新运行，或手动执行 `pip install Pillow` |
| `FileNotFoundError` | 数据路径不对 | 确保数据集目录完整，没有移动或重命名 |
| `PermissionError` | 文件被占用或权限不足 | 关闭所有打开的结果文件（如 Excel 正在打开 csv），重新运行 |
| 窗口一闪就关了 | 运行出错 | 在 cmd 中手动运行 `一键运行.bat` 看报错信息 |

### 常见问题

**Q: 我可以不用命令行吗？**
A: 可以。双击 `一键运行.bat` 即可，不需要手动输入任何命令。

**Q: 第二次运行还需要重新安装吗？**
A: 不需要。虚拟环境和依赖只安装一次，之后每次运行会直接跳到运行步骤。

**Q: 运行结果和上面表格里的数字不一样？**
A: 正常。路径计算受数据精度影响，可能略有差异。核心结论（安全路径比最短路径绕开危险路段）不会变。

**Q: 我想自己改灾害场景怎么办？**
A: 编辑 `数据集/amap_earthquake/scenario.json` 或 `数据集/amap_flood/scenario.json`，修改起点终点坐标后重新运行。

### 核心算法

- **普通最短路径**：用 Dijkstra 算法，边权重 = 道路距离
- **安全路径**：用 Dijkstra 算法，边权重 = 距离 × 风险系数 × (1 + 拥堵权重 × 拥堵度)
- 风险系数：正常 1.0、拥堵 1.4、积水 2.2、塌方 4.0
