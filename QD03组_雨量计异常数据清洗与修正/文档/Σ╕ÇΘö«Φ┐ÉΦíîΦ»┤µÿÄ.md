# 雨量计异常数据清洗与修正 一键运行说明

本目录已提供可双击运行的自包含启动程序：

`雨量计一键运行.exe`

双击后程序会自动在当前 `2_源码` 目录下运行完整实验流程，不需要先配置系统 PATH，也不要求电脑上已经安装 Python。

运行内容包括：

1. 生成/读取合成 10min 有真值雨量计数据；
2. 执行规则 QC、异常清洗、插值修正和质量标识输出；
3. 运行 Isolation Forest 辅助复核分数；自包含 exe 为控制体积和稳定性，默认跳过 torch/LSTM-AE，源码 Python 环境可另行启用 LSTM-AE；
4. 生成方法对比、消融实验和预警影响分析；
5. 读取 `data/real/raw_real_rainfall.csv` 中的 3 Rivers Wet Weather 15min 公开数据，完成真实数据迁移验证；
6. 将结果写入本目录下的 `data` 和 `output` 文件夹。

运行完成后会生成：

- `data/cleaned/rain_gauge_cleaned.csv`
- `data/processed/cleaned_with_quality_flags.csv`
- `data/real/processed_real_qc.csv`
- `output/reports/method_comparison.csv`
- `output/reports/ablation_results.csv`
- `output/reports/warning_impact.csv`
- `output/figures/*.png`
- `一键运行日志.txt`

新数据复现说明：

- 如果需要放入新的真实雨量计数据，建议替换或新增为 `data/real/raw_real_rainfall.csv`，然后双击 `雨量计一键运行.exe`。
- 真实数据 CSV 至少需要包含 `timestamp` 和 `rainfall_mm` 两列，其中 `timestamp` 应能被程序解析为时间，`rainfall_mm` 应为每个时间间隔内的毫米雨量。若原始数据单位是 inch/15min，需要先乘以 25.4 换算为 mm 后再写入 `rainfall_mm`。
- 可选字段包括 `station_id`、`source_type`、`source_name`、`source_url`、`original_unit`、`water_level_m`、`humidity_pct`、`temperature_c` 等；没有这些字段也可以运行雨量 QC 主流程。
- 新真实数据没有逐点异常真值时，程序只输出质量统计、规则可疑点、质量标识分布和清洗前后雨量变化，不计算 Precision/Recall/F1。
- 不建议直接替换 `data/raw/rain_gauge_raw.csv` 来测试无标签新数据；该路径属于合成 10min 有真值实验，若替换它，还需要同步提供匹配的 `data/raw/rain_gauge_truth.csv` 才能计算检测指标。

说明：

- 该 exe 已打包 pandas、numpy、matplotlib、scipy、scikit-learn 等核心运行依赖，双击即可复现规则 QC、Isolation Forest、消融实验、预警影响和真实 3RWW 迁移验证。
- 为控制 exe 体积并提高稳定性，自包含 exe 默认跳过 torch/LSTM-AE；报告中已经说明 LSTM-AE 只作为辅助复核，不是主方法。
- 若需要复现 LSTM-AE，可在安装 Python 的环境中执行 `python -m pip install -r requirements.txt` 和 `python -m pip install -r requirements-ml.txt`，再运行 `python src/main.py --mode all`。
- 当前电脑已验证：在临时清空 PATH、模拟找不到 Python 的情况下，`雨量计一键运行.exe` 仍然运行成功；真实数据来源识别为 `real-public-3rww`。
