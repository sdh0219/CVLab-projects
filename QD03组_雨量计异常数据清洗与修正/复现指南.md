# 第一部分 · 复现手册

## 1.1 你需要准备什么

| 需要的东西 | 说明 |
|---|---|
| Windows 电脑 | Windows 10/11，64 位 |
| Python 3.10+ | 安装见 1.2 |
| VS Code（推荐） | 安装见 1.3 |

本项目**不需要任何外部数据下载**——原始雨量数据由程序自动生成（`generate_data.py` 合成），所有输入输出都在项目内完成。

## 1.2 安装 Python

1. 访问 **https://www.python.org/downloads/** ，点黄色 **Download Python 3.x.x**
2. 双击安装包，**务必勾选 "Add python.exe to PATH"**，点 Install Now
3. 验证：`Win + R` → `cmd` 回车 → 输入 `python --version`

## 1.3 安装 VS Code

访问 **https://code.visualstudio.com/** 下载安装。

## 1.4 下载本项目

项目结构：

```
QD03组_雨量计异常数据清洗与修正/
├── 源码/
│   ├── main.py              ← 主程序入口（所有功能从这里启动）
│   ├── config.py            ← 配置文件（阈值、路径）
│   ├── generate_data.py     ← 合成雨量数据（含真值标注）
│   ├── cleaning.py          ← 规则清洗模块
│   ├── ml_anomaly.py        ← 机器学习异常检测模块
│   ├── hybrid_qc.py         ← 规则+机器学习融合决策
│   └── ...（共 19 个模块）
├── 数据集/                  ← 程序生成的原始数据与结果
└── 文档/                    ← 技术方案、检查报告、PPT
```

放到电脑上，例如 `D:\projects\QD03组_...`（建议路径无中文，中文路径多数情况也可用）。

## 1.5 安装依赖

1. 打开 `源码` 文件夹，地址栏输入 `cmd` 回车
2. 创建并激活虚拟环境：

```
python -m venv venv
venv\Scripts\activate
```

3. 安装依赖：

```
pip install -r requirements.txt
```

> 国内网络慢可先执行 `pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple`。

## 1.6 运行完整流程

执行：

```
python main.py --mode all
```

程序会自动完成：生成合成数据 → 规则清洗 → 机器学习复核 → 融合决策 → 输出评估报告。

**预期产物**（在 `数据集/` 目录）：
- `multi_sensor_raw.csv` —— 生成的原始雨量数据（含人工注入的异常）
- `cleaned_with_quality_flags.csv` —— 清洗修正后的数据 + 质量标记
- `hybrid_qc_decisions.csv` —— 每条记录的处理决策（保留/修正/剔除）
- `evaluation.json` / `method_comparison.csv` —— 效果评估（Precision / Recall / F1）
- `output/reports/` —— 图文报告

看到"全流程完成"和评估指标输出即成功。

# 第二部分 · 用户使用手册

## 2.1 这个项目是做什么的

雨量计（自动气象站）会出各种故障：传感器卡死（连续几小时数值不变）、跳变（瞬时飙到不可能的值）、堆积后清零（stuck）、超出物理上限……这些异常数据会污染降雨统计和灾害预警。

本项目做三件事：
1. **规则 QC**：按物理常识定规则（单次降雨上限、突变率、连续不变判定）标出可疑点
2. **机器学习复核**：用 Isolation Forest 和 LSTM-AE 从统计角度再查一遍
3. **融合决策**：规则 + 模型投票，给出每条记录的最终处理（保留 / 修正 / 剔除），并评估效果

```
原始雨量序列（含异常）
        │  规则 QC（物理上限 / 突变率 / 卡死 / 堆积）
        ▼
   可疑点标记
        │  ML 复核（Isolation Forest + LSTM-AE）
        ▼
   融合决策（hybrid_qc_decisions）
        │
        ▼
   清洗后的数据 + 质量标记 + 评估报告
```

## 2.2 输入与输出

**输入**：程序自动生成的合成雨量数据（`multi_sensor_raw.csv`，含真实异常标签，用于验证效果）

**输出**：
| 文件 | 内容 |
|---|---|
| `cleaned_with_quality_flags.csv` | 清洗后数据，每行带质量标记（正常/可疑/修正/剔除） |
| `hybrid_qc_decisions.csv` | 每条记录的决策依据（规则命中项、模型分数） |
| `feature_summary.csv` | 特征统计 |
| `evaluation.json` | 精确率 / 召回率 / F1 等指标 |
| 图表与报告 | 异常分布图、清洗前后对比图、评估报告 |

## 2.3 命令行功能

在 `源码` 目录（venv 激活）下：

| 命令 | 作用 |
|---|---|
| `python main.py --mode all` | 完整流程（推荐） |
| `python main.py --mode baseline` | 只跑规则 QC |
| `python main.py --mode enhanced` | 规则 QC + ML 复核 |
| `python main.py --mode real` | 用真实雨量数据做迁移验证（数据在 数据集/） |
| `python demo.py` | 快速演示（更短的输出） |

## 2.4 业务逻辑与判断标准

| 异常类型 | 判定规则（举例） | 处理 |
|---|---|---|
| 超物理上限 | 单时段降雨 > 阈值（如 60mm/10min） | 标记并修正 |
| 突变跳变 | 相邻值变化率异常大 | 标记 |
| 卡死/堆积 | 连续 N 个时段数值完全相同 | 标记 |
| 正常数据 | 通过全部规则 | 保留 |

最终结果 = 规则得分 + ML 得分的综合判断，评估指标证明清洗效果（合成数据上 F1 约 98%）。

## 2.5 常见问题

| 问题 | 原因与解决 |
|---|---|
| `torch` 安装失败 | 可先去掉 requirements 中的 torch（LSTM-AE 只是辅助模块），其余功能照常运行 |
| 运行报"找不到数据" | 确认在 `源码` 目录下运行（程序自动生成数据到 `数据集/`） |
| 想用真实数据 | 运行 `python main.py --mode real`，程序读取 数据集/ 中的真实 CSV |
