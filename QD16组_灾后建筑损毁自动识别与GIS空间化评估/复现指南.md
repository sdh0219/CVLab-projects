## 零、这个项目是做什么的

本项目用 AI 自动识别灾后建筑物的损毁程度。输入灾前和灾后的卫星影像，输出每栋建筑的损毁分级（完好 / 轻微 / 严重 / 倒塌），并生成统计图表。

项目分两条技术线：
- **A 线（核心）**：建筑物损毁识别——用深度学习模型识别损毁等级。**零基础者只需复现这条线。**
- **B 线（进阶）**：无人机 DSM 方量估算——用无人机三维数据估算损毁方量。需要额外安装 GDAL，零基础者可跳过。

**你需要准备：**

- 一台 Windows 电脑（Mac/Linux 也可，但步骤以 Windows 为例）
- 能上网的网络（安装依赖时需要下载约 500 MB）
- 预计耗时：**15 分钟**（含依赖安装），再次运行只需 1 分钟
- 不需要 GPU——本指南使用 CPU 模式（速度稍慢但人人可用）

## 一、安装 Python（已装可跳过）

### 1.1 下载 Python

1. 打开浏览器，访问：https://www.python.org/downloads/
2. 点击黄色按钮 **"Download Python 3.x.x"**
3. 等待下载完成（约 25 MB）

### 1.2 安装 Python（关键步骤！）

1. 双击下载的安装包
2. **先勾选底部 "Add Python to PATH"** ← 非常重要！不勾选后面会报错
3. 点击 **"Install Now"**
4. 等待安装完成，点击 **"Close"**

### 1.3 验证安装

1. 按 `Win + R`，输入 `cmd`，按回车
2. 输入 `python --version`，按回车
3. 显示 `Python 3.10.x` 或更高版本 = 安装成功 ✓

按 `Win + R` → 输入 `cmd` → 按回车，然后进入项目目录：

```

```

```

```

> 这里用 CPU 版 PyTorch（不需要 GPU），下载约 500 MB，请耐心等待。

> `set FORCE_CPU=1` 强制使用 CPU，避免没有 GPU 时报错。

### 4.5 生成统计

```
".venv\Scripts\python.exe" stats.py
```

## 六、遇到问题怎么办

### 报错对照表

| 报错信息 | 原因 | 解决方案 |
|---|---|---|
| `'python' 不是内部或外部命令` | Python 未安装或未加入 PATH | 重新安装 Python，勾选 "Add Python to PATH" |
| `best.pth 不存在` | 预训练权重文件缺失 | 从项目提供者处获取 best.pth，放到 `outputs\checkpoints\` 目录 |
| `CUDA out of memory` | GPU 显存不足 | 一键脚本已默认 CPU 模式；手动运行时确保 `set FORCE_CPU=1` |
| `cv2.error` 或 `NoneType` | 中文路径问题 | 把项目移到纯英文路径（如 `D:\projects\16group\`） |
| `ModuleNotFoundError: No module named 'torch'` | PyTorch 未安装 | 重新双击 `一键运行.bat`，或手动执行第四章的安装命令 |
| `待推理样本: 0` | 测试数据缺失 | 检查 `数据集\aline_dataset\test_ex\` 目录是否有影像文件 |
| `RuntimeError: Error(s) in loading state_dict` | 权重与代码版本不匹配 | 确认 best.pth 是本项目的权重，不是其他项目的 |

### 常见问题

**Q: 安装依赖很慢怎么办？**
A: PyTorch 约 500 MB，首次安装需要几分钟。可以配置国内镜像加速：
```
".venv\Scripts\python.exe" -m pip install opencv-python shapely matplotlib tqdm numpy -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**Q: 没有 GPU 能运行吗？**
A: 可以。一键脚本默认使用 CPU 模式。推理速度比 GPU 慢（约 30 秒 vs 5 秒），但结果完全一样。

**Q: 推理结果只有少量图片？**
A: 正常。预测目录已精简为 11 个灾害事件各 2 个样本的示例。如需完整推理结果，运行 `inference.py` 会重新生成。

**Q: 我想用 GPU 加速怎么办？**
A: 安装 GPU 版 PyTorch：访问 https://pytorch.org/ ，按官网指引选择 CUDA 版本安装命令。然后不要设置 `FORCE_CPU=1`。

### 核心算法

- 模型用**孪生 U-Net**：编码器共享权重，吃灾前/灾后两张影像，逐栋识别损毁等级
- xBD 官方 4 级标度：no-damage / minor / major / destroyed
- 面积换算：`面积(m²) = 像素数 × GSD²`（GSD = 地面分辨率，默认 1 米/像素）

> 如复现中遇到问题，可对照 `源码/aline/README.md` 排查。
