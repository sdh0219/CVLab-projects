# QD05 · 基于 LSTM 的洪水水位监测 · 零基础复现与使用指南

> 本指南面向零基础同学。跟着"复现手册"一步步做，就能把项目跑起来；再看"用户使用手册"理解它是什么、怎么用。

> **项目一句话**：用深度学习（LSTM 长短时记忆网络）根据历史水位记录，预测未来几天的河流水位，提前发现洪水风险。

# 第一部分 · 复现手册

## 1.1 你需要准备什么

| 需要的东西 | 说明 |
|---|---|
| Windows 电脑 | Windows 10/11，64 位 |
| Python 3.10+ | 安装见 1.2 |
| VS Code（推荐） | 安装见 1.3 |

本项目所需的**历史水位数据已经放在 `数据集/` 目录**（美国 USGS 河流水位站公开数据），无需联网下载。

## 1.2 安装 Python

1. 访问 **https://www.python.org/downloads/** ，点黄色 **Download Python 3.x.x**
2. 双击安装包，**务必勾选 "Add python.exe to PATH"**，点 Install Now
3. 验证：`Win + R` → `cmd` 回车 → 输入 `python --version`

## 1.3 安装 VS Code

访问 **https://code.visualstudio.com/** 下载安装。

## 1.4 下载本项目

项目结构：

```
QD05组_基于LSTM的洪水水位监测/
├── 源码/
│   ├── train_lstm.py        ← 主程序：训练模型 + 预测水位（先跑这个）
│   ├── config.py            ← 配置（路径、超参数）
│   ├── download_usgs.py     ← （可选）重新下载 USGS 水位数据
│   └── build_ppt.py         ← 生成汇报 PPT
├── 数据集/
│   ├── usgs_05464500_daily.csv       ← 河流水位日数据
│   ├── usgs_05464500_instantaneous.json ← 高精度水位数据
│   └── open_meteo_era5_hourly_precipitation.json ← 降雨数据
└── 文档/                    ← 技术方案与报告
```

放到电脑上，例如 `D:\projects\QD05组_...`。

## 1.5 安装依赖

本项目使用 TensorFlow（深度学习框架），安装体积较大（约 500MB），请耐心等待。

1. 打开 `源码` 文件夹，地址栏输入 `cmd` 回车
2. 创建并激活虚拟环境：

```
python -m venv venv
venv\Scripts\activate
```

3. 安装依赖（requirements.txt 已随项目提供）：

```
pip install -r requirements.txt
```

> 国内网络慢：先执行 `pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple`。
> 如果 TensorFlow 安装失败，尝试：`pip install tensorflow-cpu`（CPU 版，本项目用 CPU 即可）。

## 1.6 训练模型并预测

执行：

```
python train_lstm.py
```

程序会：
1. 读取 `数据集/` 中的水位数据
2. 构造时间序列样本（用过去 N 天预测未来 M 天）
3. 训练 LSTM 和 BiLSTM 两个模型（CPU 约 5-15 分钟）
4. 输出预测结果和对比图表

**预期产物**（在 `源码/outputs/` 目录）：
- `lstm_water_level_model.keras` / `bilstm_water_level_model.keras` —— 训练好的模型
- `prediction_result.csv` —— 预测值与真实值对照
- `future_forecast.csv` —— 未来水位预测
- `prediction_plot.png` / `risk_plot.png` —— 预测曲线与风险图
- `model_comparison.png` —— LSTM 与 BiLSTM 效果对比

看到训练完成、预测图生成即成功。

# 第二部分 · 用户使用手册

## 2.1 这个项目是做什么的

河流水位是洪水预警的核心指标。水位站每小时都在记录数据，但**人工看曲线很难提前判断未来走势**。

本项目用 LSTM（一种擅长处理时间序列的深度学习网络）学习"水位的历史变化规律"，然后：
- 预测未来 1-7 天的水位
- 对比两种模型（LSTM 与 BiLSTM）谁更准
- 绘制风险图，直观看到是否会接近警戒水位

```
历史水位数据（日/小时级）
        │  数据清洗 + 时间序列切窗（过去 N 天 → 未来 M 天）
        ▼
   训练集 / 测试集
        │  训练 LSTM 与 BiLSTM 模型
        ▼
   训练好的模型
        │  输入最新水位 → 预测
        ▼
   未来水位预测 + 风险等级图 + 模型对比报告
```

## 2.2 输入与输出

**输入**（`数据集/`）：
| 文件 | 内容 |
|---|---|
| `usgs_05464500_daily.csv` | 河流水位逐日记录（站点 05464500，Cedar Rapids） |
| `usgs_05464500_instantaneous.json` | 逐小时高精度水位 |
| `open_meteo_era5_hourly_precipitation.json` | 逐小时降雨量 |

**输出**（`源码/outputs/`）：
| 文件 | 内容 |
|---|---|
| 模型文件（.keras） | 训练好的 LSTM / BiLSTM |
| `prediction_result.csv` | 测试集上的预测 vs 真实值 |
| `future_forecast.csv` | 未来水位预测序列 |
| 图表 | 预测曲线、风险图、模型对比 |

## 2.3 主要功能与操作

| 功能 | 命令 | 说明 |
|---|---|---|
| 训练 + 预测（主流程） | `python train_lstm.py` | 训练两个模型并输出全部结果 |
| 重新下载数据（可选） | `python download_usgs.py` | 从 USGS 官网拉最新数据（需联网） |
| 生成汇报 PPT | `python build_ppt.py` | 把图表打包成 PPT |

修改预测天数等参数：用 VS Code 打开 `config.py`，改对应数值保存后重新运行即可。

## 2.4 业务逻辑流程

```
逐日/逐小时水位 + 降雨
   → 滑动窗口构造样本：输入 = 过去 7 天水位序列
   → LSTM / BiLSTM 学习序列规律
   → 测试集验证（MAE / RMSE / R² 指标）
   → 对未来水位外推预测
   → 对照防洪警戒线，输出风险提示
```

预测不准时会看到较大误差——这也是学习的重点：理解模型的能力边界，而不是盲信预测。

## 2.5 常见问题

| 问题 | 原因与解决 |
|---|---|
| TensorFlow 装不上 | 用清华镜像重试；或装 CPU 版 `pip install tensorflow-cpu` |
| 训练太慢 | 项目默认 CPU 即可；缩短数据窗口或减少训练轮数（改 config.py） |
| 报"找不到数据" | 确认在 `源码` 目录下运行，`数据集/` 与 `源码/` 同级 |
| 图表乱码 | 若中文标签显示方块，是系统缺中文字体，不影响结果数据 |
