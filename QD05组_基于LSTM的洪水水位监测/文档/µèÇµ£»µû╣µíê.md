# 基于 LSTM 的洪水水位预测技术方案

## 项目概述

本项目属于"模块2：监测预警"，使用长短期记忆网络（LSTM）对 Cedar River 水文站的水位数据进行时间序列预测，实现未来24小时水位预测和洪水风险预警。

---

## 1. 洪水预测问题描述

### 1.1 研究背景

洪水是常见的自然灾害，对沿岸城市的安全构成严重威胁。美国 Cedar Rapids 市位于 Cedar River 沿岸，2008年曾发生极端洪水事件，峰值水位达到31.12英尺，造成重大经济损失。建立准确的水位预测系统，能够提前识别水位上涨趋势，为防洪决策提供量化依据。

### 1.2 预测任务

- **研究对象**：USGS 站点 05464500 (Cedar River at Cedar Rapids, IA)
- **预测目标**：未来24小时水位高度（Gage height, 单位：ft）
- **输入特征**：过去72小时的水位、流量、降雨量数据
- **输出结果**：24小时水位预测序列及风险等级分类

### 1.3 技术挑战

- 时间序列数据具有复杂的非线性特征
- 水位变化受降雨、流量等多因素影响
- 需要处理数据缺失、时间对齐等问题
- 需要平衡预测精度与计算效率

## 3. LSTM 模型结构

### 3.1 模型架构

采用双层 LSTM 结构，配合 Dropout 层防止过拟合：

```
输入层 (Input)
  ↓
LSTM层 (64 units, return_sequences=True)
  ↓
Dropout层 (0.2)
  ↓
LSTM层 (32 units)
  ↓
Dropout层 (0.2)
  ↓
Dense层 (32 units, ReLU激活)
  ↓
输出层 (24 units)
```

### 3.2 模型参数

| 参数名称 | 参数值 | 说明 |
|---------|--------|------|
| 输入维度 | (72, 3) | 72小时窗口，3个特征 |
| LSTM单元数 | 64 → 32 | 双层递减结构 |
| Dropout率 | 0.2 | 防止过拟合 |
| Dense单元数 | 32 | 特征提取层 |
| 输出维度 | 24 | 预测未来24小时 |

### 3.3 模型实现代码

```python
def build_model(n_features: int) -> Sequential:
    model = Sequential([
        Input(shape=(WINDOW_SIZE, n_features)),
        LSTM(64, return_sequences=True),
        Dropout(0.2),
        LSTM(32),
        Dropout(0.2),
        Dense(32, activation="relu"),
        Dense(FORECAST_HORIZON),
    ])
    model.compile(optimizer=Adam(learning_rate=0.001), loss="mse")
    return model
```

## 5. 滑动窗口构造

### 5.1 样本构造方法

使用滑动窗口方法构造训练样本：

- **输入窗口**：过去72小时的特征数据
- **输出窗口**：未来24小时的水位数据
- **滑动步长**：1小时

### 5.2 实现代码

```python
def create_sequences(values: np.ndarray, target: np.ndarray):
    features = []
    labels = []
    max_start = len(values) - WINDOW_SIZE - FORECAST_HORIZON + 1
    
    for start in range(max_start):
        end = start + WINDOW_SIZE
        features.append(values[start:end])
        labels.append(target[end:end+FORECAST_HORIZON])
    
    return np.array(features), np.array(labels)
```

### 5.3 样本形式

- **输入样本 X**：形状为 `(样本数, 72, 3)`
- **输出样本 y**：形状为 `(样本数, 24)`
- **特征维度**：水位、流量、降雨量

## 6. 评价指标

### 6.1 评价指标选择

采用三个标准评价指标评估模型性能：

1. **平均绝对误差（MAE）**
   - 公式：MAE = (1/n) Σ|y_true - y_pred|
   - 单位：ft
   - 含义：预测值与真实值的平均偏差

2. **均方根误差（RMSE）**
   - 公式：RMSE = √[(1/n) Σ(y_true - y_pred)²]
   - 单位：ft
   - 含义：预测误差的标准差

3. **决定系数（R²）**
   - 公式：R² = 1 - Σ(y_true - y_pred)² / Σ(y_true - y_mean)²
   - 范围：[0, 1]
   - 含义：模型解释方差的比例

### 6.2 实际评价结果

| 预测小时 | MAE (ft) | RMSE (ft) | R² |
|---------|----------|-----------|-----|
| 第1小时 | 0.114 | 0.236 | 0.984 |
| 第12小时 | 0.134 | 0.239 | 0.984 |
| 第24小时 | 0.156 | 0.283 | 0.977 |

### 6.3 结果分析

- **短时预测精度高**：第1小时 R² = 0.984，MAE = 0.114 ft
- **长时预测仍可靠**：第24小时 R² = 0.977，RMSE = 0.283 ft
- **误差随时间递增**：符合时间序列预测的一般规律

## 7. 风险等级分类

### 7.1 风险阈值定义

根据 USGS 洪水等级标准，定义风险阈值：

| 风险等级 | 水位范围 (ft) | 含义 |
|---------|--------------|------|
| normal | < 10.0 | 正常水位 |
| action | 10.0 - 12.0 | 行动水位（需关注） |
| minor | 12.0 - 14.0 | 轻微洪水 |
| moderate | 14.0 - 16.0 | 中度洪水 |
| major | ≥ 16.0 | 严重洪水 |

### 7.2 分类实现

```python
def classify_risk(stage_ft: float) -> str:
    if stage_ft >= RISK_THRESHOLDS_FT["major"]:
        return "major"
    if stage_ft >= RISK_THRESHOLDS_FT["moderate"]:
        return "moderate"
    if stage_ft >= RISK_THRESHOLDS_FT["minor"]:
        return "minor"
    if stage_ft >= RISK_THRESHOLDS_FT["action"]:
        return "action"
    return "normal"
```
