## 零、这个项目是做什么的

本项目用机器学习预测**地震后一个地区经济恢复需要几年**。

简单说：发生地震后，当地 GDP 会下滑，然后逐年恢复。本项目把美国历年地震和各州 GDP 数据喂给模型，让它学会预测"几年能恢复"。

- **数据来源**：USGS 地震目录、NOAA 重大地震损失数据库、BEA（美国经济分析局）州级 GDP——均为公开数据，**项目已内置，无需自己下载**
- **模型**：训练两种树模型（随机森林 + 梯度提升树），对比哪个预测得更准
- **输出**：模型评估指标、混淆矩阵图、特征重要性图，以及一份**自动生成的汇报 PPT**

**你需要准备：**

- 一台 Windows 电脑（Mac/Linux 也可以，但下面步骤以 Windows 为例）
- 能上网的网络（安装依赖时需要）
- 预计耗时：**约 8 分钟**（从零开始，含安装 Python）；**约 5 分钟**（已装好 Python）

## 一、安装 Python（已装可跳过）

### 1.1 下载 Python

1. 打开浏览器，访问：https://www.python.org/downloads/
2. 点击页面上黄色的 **"Download Python 3.x.x"** 按钮
3. 等待下载完成（文件约 25 MB）

### 1.2 安装 Python（关键步骤！）

1. 找到下载的安装包（通常在"下载"文件夹），**双击运行**
2. 安装界面打开后，你会看到两个大按钮和底部有一行小字
3. **先勾选底部 "Add Python to PATH"** ← 这一步非常重要！不勾选后面会报错
4. 然后点击 **"Install Now"**
5. 等待进度条走完（约 30 秒），点击 **"Close"** 关闭

### 1.3 验证安装成功

1. 按键盘 `Win + R`（同时按 Windows 键和 R 键），弹出"运行"窗口
2. 输入 `cmd`，按回车，会弹出一个黑色窗口
3. 在黑色窗口中输入以下命令，然后按回车：

   ```
   python --version
   ```

4. 如果显示 `Python 3.10.x`（或更高版本号），说明安装成功 ✓
5. 如果显示"不是内部或外部命令"，说明第 3 步的"Add to PATH"没勾选，请重新安装

## 四、分步运行（想了解每步做了什么）

如果你想自己手动操作，可以按以下步骤进行。**每一步都可以直接复制粘贴到命令行执行。**

### 4.1 打开命令行

1. 按 `Win + R`，输入 `cmd`，按回车
2. 用 `cd` 命令进入项目的源码目录（把路径换成你自己的实际路径）：

   ```
   cd /d D:\你的路径\17组_灾后经济恢复周期预测\源码
   ```

### 4.2 创建虚拟环境并安装依赖

```
python -m venv .venv
".venv\Scripts\python.exe" -m pip install -r requirements.txt
```

> **什么是虚拟环境？** 就是一个独立的 Python 环境文件夹（`.venv`），装在这里的依赖不会影响你电脑上其他 Python 项目。
>
> 如果安装很慢或失败，可换国内镜像，把第二条命令换成：
> ```
> ".venv\Scripts\python.exe" -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
> ```

### 4.3 建立数据目录链接（关键，只需一次）

代码默认从 `源码\data\` 读数据，但数据实际在 `数据集\`。下面这条命令把 `数据集` 链接成 `源码\data`，让代码能找到数据：

```
mklink /J data "..\数据集"
```

> `mklink /J` 是 Windows 自带的目录联接命令，普通用户即可执行，**不需要管理员权限**，也不复制数据。执行成功后 `源码\data\raw` 就等于 `数据集\raw`。**只需执行一次，以后再运行不用重复。**

### 4.4（可选）下载原始数据

数据已经内置在 `数据集\raw\`，**通常跳过这一步**。如果你确实想重新下载最新数据：

```
".venv\Scripts\python.exe" download_data.py
```

数据来源（均为公开免费）：
- USGS 地震目录：https://earthquake.usgs.gov/
- NOAA 重大地震数据库：https://www.ngdc.noaa.gov/
- BEA 地区经济账户：https://apps.bea.gov/

> 下载依赖网络，可能较慢或偶发失败。失败也没关系，用内置数据即可继续。

### 4.5 生成探索性整合数据

```
".venv\Scripts\python.exe" process_data.py
```

### 4.6 生成建模数据集（1500 行）

```
".venv\Scripts\python.exe" prepare_rf_recovery_dataset.py --limit 1500 --output earthquake_rf_recovery_dataset_1500.csv
```

### 4.7 训练梯度提升树（GBDT）

```
".venv\Scripts\python.exe" train_gradient_boosting_recovery.py
```

> 这一步生成的结果在 `outputs\gradient_boosting_recovery_1500_improved_balanced\`，**下一步的 PPT 依赖它**，必须先训练 GBDT。

### 4.8 训练随机森林（RF）

为便于和 GBDT 对比，这里让随机森林用同一份 1500 行数据：

```
".venv\Scripts\python.exe" train_random_forest_recovery.py --data-path "data\processed\earthquake_rf_recovery_dataset_1500.csv" --feature-path "data\processed\earthquake_recovery_feature_columns.txt" --output-dir "outputs\random_forest_recovery_1500"
```

> 这三个 `--xxx` 参数告诉脚本用哪份数据、哪个特征清单、结果存到哪。一键运行脚本已自动带好这些参数，手动运行时照抄即可。

### 4.9 生成汇报 PPT

```
".venv\Scripts\python.exe" generate_recovery_ppt.py
```

### 4.10（可选）生成 GBDT 原理流程图

```
".venv\Scripts\python.exe" create_gbdt_principle_flowchart.py
```

## 六、遇到问题怎么办

### 报错对照表

| 报错信息 | 原因 | 解决方案 |
|---|---|---|
| `'python' 不是内部或外部命令` | Python 未安装或未加入 PATH | 重新安装 Python，务必勾选 "Add Python to PATH" |
| `ModuleNotFoundError: No module named 'pandas'` 等 | 依赖未安装 | 双击 `一键运行.bat` 重新运行；或手动执行 `".venv\Scripts\python.exe" -m pip install -r requirements.txt` |
| `FileNotFoundError: ... data\raw\...` | 数据目录链接没建立 | 在 `源码\` 下执行 `mklink /J data "..\数据集"` |
| `Feature columns are missing from dataset` | 随机森林用了旧版数据 | 用 4.8 节带 `--data-path` 参数的命令，让它用 1500 行数据集 |
| PPT 生成失败 / `FileNotFoundError: ...joblib` | 没先训练 GBDT | 必须先跑 4.7 节 GBDT 训练，再跑 4.9 节生成 PPT |
| `OneHotEncoder ... 'sparse_output'` 参数错误 | scikit-learn 版本太低 | 升级到 scikit-learn 1.2+：`pip install -U scikit-learn` |
| 图表中文显示成方框 | 系统缺中文字体 | Windows 一般自带"微软雅黑"，通常不会出现；若出现，安装一款中文字体即可 |
| `download_data.py` 联网失败 | BEA / USGS / NOAA 接口波动 | 数据已内置，跳过下载即可；或重试 |
| 黑窗口一闪就关了 | 运行出错 | 在 cmd 中手动 `cd /d 源码路径` 后执行 `一键运行.bat`，看完整报错 |

### 常见问题

**Q: 我可以不用命令行吗？**
A: 可以。双击 `一键运行.bat` 即可，不需要手动输入任何命令。

**Q: 第二次运行还需要重新安装吗？**
A: 不需要。虚拟环境、依赖、数据链接都只弄一次，之后每次运行会直接跳到训练步骤。

**Q: 两次运行的结果（准确率）不一样？**
A: 脚本已固定随机种子（42），同版本依赖下结果可复现。若换了 scikit-learn 版本，数值可能略有差异，但模型能跑通、能生成 PPT 即视为复现成功。

**Q: 想让随机森林和梯度提升树用不同数据怎么办？**
A: 本指南为便于对比，让两个模型用同一份 1500 行数据。如需让随机森林用 2000 行数据，先执行 `prepare_rf_recovery_dataset.py --limit 2000`，再不带 `--data-path` 参数运行 `train_random_forest_recovery.py`。

**Q: 我想改恢复周期窗口（比如看灾后 5 年）怎么办？**
A: 运行 `prepare_rf_recovery_dataset.py --limit 1500 --output earthquake_rf_recovery_dataset_1500.csv --max-horizon 5`（默认是 3 年）。注意窗口越大，可用样本越少。

### 核心思路

- **恢复周期标签**：以灾前一年实际 GDP 为基线，灾害当年或灾后第 1/2/3 年 GDP 回到或超过基线，分别记为 0/1/2/3 年恢复；3 年内未恢复记为 4。标签由 BEA 实际 GDP 客观计算，避免人工主观标注。
- **预测任务**：5 类（0–4）多分类问题。
- **模型对比**：随机森林（集成多棵独立树投票）vs 梯度提升树（逐棵修正前一棵的误差）。两者都启用类别加权，处理"当年就恢复（0 类）样本偏多"的不均衡问题。
- **严格验证**：按"区域+年份"分组划分训练/测试集，避免同一地区同年的样本同时进训练集和测试集造成数据泄漏。
- **汇报 PPT**：基于梯度提升树的结果，自动绘制 10 张图表并组装成 13 页汇报材料。

> 如复现中遇到问题，可对照 `源码/README.md` 排查，或联系项目提供者。
