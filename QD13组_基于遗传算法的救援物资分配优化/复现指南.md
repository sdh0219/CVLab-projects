## 零、这个项目是做什么的

本项目模拟 2021 年 7 月河南极端暴雨洪灾场景下的救援物资分配。面对多个仓库、多个受灾点、多种物资，用**遗传算法**计算一个"最优分配方案"——告诉每个仓库该把多少物资送到哪个受灾点。

优化目标兼顾五个方面：物资满足率、运输成本、分配公平性、灾情紧急程度、时间效率。项目还提供一套 Web 可视化大屏，能直观看到分配结果、雷达图、收敛曲线。

**你需要准备：**

- 一台 Windows 电脑（Mac/Linux 也可以，但下面步骤以 Windows 为例）
- 能上网的网络（安装依赖时需要）
- **必装**：Python 3.10+
- **可选**：Node.js 18+（仅当你想看交互式 Web 可视化大屏时才需要；不装也能用"仅后端"模式看到图表结果）
- 预计耗时：**5 分钟**（已装好 Python）或 **15 分钟**（从零开始装 Python）

> 看到这里如果有点懵，记住一句话：**先装 Python，再双击 `一键运行.bat`，剩下交给脚本。**

## 一、安装 Python（已装可跳过）

### 1.1 下载 Python

1. 打开浏览器，访问：https://www.python.org/downloads/
2. 点击页面上黄色的 **"Download Python 3.x.x"** 按钮
3. 等待下载完成（文件约 25 MB）

### 1.2 安装 Python（关键步骤！）

1. 找到下载的安装包（通常在"下载"文件夹），**双击运行**
2. 安装界面打开后，你会看到两个大按钮和底部有一行小字
3. **先勾选底部 "Add Python to PATH"** ← 这一步非常重要！不勾选后面会报错
4. 然后点击 **"Install Now"**
5. 等待进度条走完（约 30 秒），点击 **"Close"** 关闭

### 1.3 验证安装成功

1. 按键盘 `Win + R`（同时按 Windows 键和 R 键），弹出"运行"窗口
2. 输入 `cmd`，按回车，会弹出一个黑色窗口
3. 在黑色窗口中输入以下命令，然后按回车：

   ```
   python --version
   ```

4. 如果显示 `Python 3.10.x`（或更高版本号），说明安装成功 ✓
5. 如果显示"不是内部或外部命令"，说明第 3 步的"Add Python to PATH"没勾选，请重新安装

### 1.4 （可选）安装 Node.js

只有当你想看 **Web 可视化大屏**时才需要装。只看后端图表结果可以跳过本步。

1. 访问：https://nodejs.org/
2. 下载 **LTS 长期支持版**（按钮上会写"LTS"）
3. 双击安装包，一路点"下一步"即可，无需任何特殊设置
4. 安装完成后，重新打开一个 cmd 窗口，输入验证：

   ```
   node --version
   ```

   显示 `v18.x.x` 或更高即成功 ✓

## 六、遇到问题怎么办

### 报错对照表

| 报错信息 | 原因 | 解决方案 |
|---|---|---|
| `'python' 不是内部或外部命令` | Python 未安装或未加入 PATH | 重新安装 Python，务必勾选 "Add Python to PATH"（见 1.2 节） |
| `ModuleNotFoundError: No module named 'numpy'` | Python 依赖未安装 | 双击 `一键运行.bat` 重新运行，或手动执行 `pip install -r requirements.txt` |
| `ModuleNotFoundError: No module named 'flask'` | Flask 未安装 | 同上，运行 `pip install -r requirements.txt` |
| `'npm' 不是内部或外部命令` | Node.js 未安装（仅影响 Web 大屏） | 装 Node.js 18+（见 1.4 节）；或继续用"仅后端"模式看图表结果 |
| `FileNotFoundError: ... henan_disaster_processed_data.py` | 数据路径不对 | 确保项目目录完整，没有移动或重命名 `数据集\` 或 `源码\code\data\` |
| `Port 5180 is already in use` | 前端端口被占用 | 关闭占用 5180 端口的程序，或修改 `源码\frontend\vite.config.js` 中的端口 |
| `Port 5181 is already in use` | 后端 API 端口被占用 | 关闭占用 5181 端口的程序，或设置环境变量 `API_PORT` 后再运行 |
| 前端打开是空白 / 无数据 | results.json 未生成 | 先运行 `python code\export_for_frontend.py` 生成数据，再启动前端 |
| `SyntaxError: (unicode error)` | 中文路径编码问题 | 确保终端用 UTF-8：在 cmd 执行 `chcp 65001`；路径含中文时避免过深嵌套 |
| 窗口一闪就关了 | 运行出错 | 在 cmd 中手动进入 `源码` 目录，输入 `一键运行.bat` 看完整报错 |
| `pip install` 卡住或超时 | 网络问题 | 配置国内镜像：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple` |

### 常见问题

**Q: 我可以不用命令行吗？**
A: 可以。双击 `一键运行.bat` 即可，不需要手动输入任何命令。

**Q: 第二次运行还需要重新安装吗？**
A: 不需要。虚拟环境（`.venv`）和依赖只安装一次，之后每次运行会自动跳到运行步骤。前端 `node_modules` 也是装一次就行。

**Q: 我没装 Node.js，能复现项目吗？**
A: 能。一键脚本会自动走"仅后端"模式，运行遗传算法生成 3 张 PNG 图表结果到 `源码\output\`，双击即可查看。Web 交互式大屏是增强体验，不影响核心算法复现。

**Q: 运行结果和上面表格里的数字不一样？**
A: 正常。遗传算法含随机性（初始种群、交叉、变异），每次运行结果会略有差异。核心结论（优化方案优于人工方案）不会变。想让结果可复现，可在 `code\main.py` 开头加 `np.random.seed(42)`。

**Q: 想换一个数据集运行怎么办？**
A: 用通用版主程序。编辑 `源码\code\config.json`，把 `data.disaster_points_file` 改成目标数据集路径（相对 `code/` 目录），然后运行：
```
".venv\Scripts\python.exe" "code\main_universal.py"
```
可选数据集见 `数据集\` 下的 `dataset_01_large_scale`、`dataset_02_complex_scenario`，配置模板见 `数据集\config_examples\`。

**Q: 想调算法参数（种群大小、迭代次数等）？**
A: 编辑 `源码\code\config.json` 的 `algorithm` 区块。例如把 `generations` 从 50 改成 100，算法会迭代更久、结果更优但更慢。

**Q: 黑色窗口能关吗？**
A: 如果是"仅后端"模式，运行完显示结果后可以关。如果是"完整系统"模式（启动了 Web 大屏），**不要关黑色窗口**，关了服务就停了；先看完大屏，再回窗口按 `Ctrl+C` 优雅停止。

**Q: 怎么停止 Web 服务？**
A: 在运行 `start.py` 的黑色窗口里按 `Ctrl+C`。

- **遗传算法**：种群大小 100、迭代 50 代、变异率 0.1、交叉率 0.8、精英保留 10%
