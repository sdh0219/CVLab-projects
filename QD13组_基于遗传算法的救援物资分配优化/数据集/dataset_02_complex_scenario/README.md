# 数据集 02：复杂场景多灾害应急调度

## 场景说明

本数据集模拟**多灾害类型、多物资品类、异构仓库与复杂通行条件**下的应急调度场景，重点体现**数据描述复杂、约束维度丰富**的特点。

## 复杂特征

- **5种灾害类型**：洪水、内涝、山体滑坡、堰塞湖、复合灾害
- **5级通行条件**：良好 / 一般 / 较差 / 极差 / 中断
- **5类物资**：饮用水、食品、帐篷、药品、发电设备
- **异构仓库**：省级中心库、医疗专长库、山地应急库等
- **配送时间窗**：各受灾点设置不同配送时限（小时）
- **优先级分级**：一级 / 二级 / 三级紧急响应

## 数据规模

| 项目 | 数值 |
|------|------|
| 受灾点 | 15 个 |
| 储备仓库 | 6 个 |
| 物资类型 | 5 种 |
| 受灾人口 | 878,600 人 |
| 总需求量 | 3,555,974 单位 |
| 总库存量 | 989,000 单位 |
