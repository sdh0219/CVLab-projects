## 零、这个项目是做什么的

本项目模拟一套**山区泥石流灾害的 AI 辅助"零死亡"综合防控方案**。用真实 GIS 栅格数据（12 层地理信息）和加密的灾害数据库，自动完成从"风险评估 → 降雨预警 → 群众转移 → 救援调度"的全流程，并出图出表。

跑一遍你会得到：

- **6 张分析图**：泥石流易发性图、风险等级图、监测站点图、分级预警图、转移路线图、DEM 高程对比图
- **1 个数据表**（`grid_data.csv`，Excel 可打开）：每个像元的 10 因子得分、易发性指数、风险等级
- **5 个 JSON 结果**：监测站点、转移计划、预警规则、救援力量、高风险聚落

项目有两个特别之处（也是本指南重点）：

1. **数据是加密的**：`数据集/database_data/` 下的 `.enc` 文件用 AES-256-CBC 加密，运行时需要先解密。
2. **有自研授权机制**：要先在本机生成一个"授权文件"（`.license`），主程序才肯运行。授权**绑定你这台电脑**，且是**单次使用**（跑一次主程序就作废，下次要重新生成）。

**你需要准备：**

- 一台 Windows 电脑（Mac/Linux 也可以，但下面步骤以 Windows 为例）
- 能上网的网络（安装依赖时需要）
- 预计耗时：**5 分钟**（已装好 Python）或 **20 分钟**（从零开始，含 rasterio 安装）

> **关于 rasterio（最大的安装障碍）**：本项目依赖 `rasterio` 库读取地理栅格文件，它在 Windows 下偶尔装不上（依赖 GDAL 库）。如果一键脚本装不上，第六章 6.5 节给了 conda 方案的详细步骤——这是本指南最关键的一段，请耐心看。

## 一、安装 Python（已装可跳过）

### 1.1 下载 Python

1. 打开浏览器，访问：https://www.python.org/downloads/
2. 点击页面上黄色的 **"Download Python 3.x.x"** 按钮
3. 等待下载完成（文件约 25 MB）

> **版本建议**：选 **Python 3.10 / 3.11 / 3.12** 之一最稳妥（项目依赖已在该范围测试）。3.13 也可以，但若 rasterio 装不上请优先用 3.10~3.12。

### 1.2 安装 Python（关键步骤！）

1. 找到下载的安装包（通常在"下载"文件夹），**双击运行**
2. 安装界面打开后，你会看到两个大按钮和底部有一行小字
3. **先勾选底部 "Add Python to PATH"** ← 这一步非常重要！不勾选后面会报错
4. 然后点击 **"Install Now"**
5. 等待进度条走完（约 30 秒），点击 **"Close"** 关闭

### 1.3 验证安装成功

1. 按键盘 `Win + R`（同时按 Windows 键和 R 键），弹出"运行"窗口
2. 输入 `cmd`，按回车，会弹出一个黑色窗口
3. 在黑色窗口中输入以下命令，然后按回车：

   ```
   python --version
   ```

4. 如果显示 `Python 3.10.x`（或更高版本号），说明安装成功 ✓
5. 如果显示"不是内部或外部命令"，说明第 3 步的"Add to PATH"没勾选，请重新安装

## 四、分步运行（想了解每步做了什么）

如果你想自己手动操作，可以按以下步骤进行。命令都在 **`源码`** 目录下执行。

### 4.1 打开命令行并进入源码目录

1. 按 `Win + R`，输入 `cmd`，按回车
2. 用 `cd` 命令进入项目的源码目录（把路径换成你自己的实际路径）：

   ```
   cd /d D:\你的路径\18组_AI辅助山区泥石流零死亡方案\源码
   ```

### 4.2 创建虚拟环境并安装依赖

```
python -m venv .venv
".venv\Scripts\python.exe" -m pip install --upgrade pip
```

先装好装的几个：

```
".venv\Scripts\python.exe" -m pip install numpy==2.2.6 matplotlib==3.10.9 pycryptodome==3.23.0 psycopg2-binary==2.9.12
```

再单独装 rasterio（容易出问题的那个，详见 6.5）：

```
".venv\Scripts\python.exe" -m pip install rasterio==1.4.4
```

验证 rasterio 是否真的能用（不报错就是成功）：

```
".venv\Scripts\python.exe" -c "import rasterio; print(rasterio.__version__)"
```

> **什么是虚拟环境？** 就是一个独立的 Python 环境文件夹（`.venv`），装在这里的依赖不会影响你电脑上其他 Python 项目。

### 4.3 生成授权 license

```
".venv\Scripts\python.exe" keygen.py
```

这会在 `源码/` 目录下生成一个 `.license` 文件，并打印你的设备指纹、授权文件路径。

> **重点**：license 是**单次授权**，跑一次 `main.py` 就作废。所以**每次运行主程序之前都要先重新跑一次 `keygen.py`**，否则会报"授权已用完"。
>
> **必须在同一台电脑上**生成和运行——它绑定你电脑的 MAC 地址和主机名，换台电脑或换虚拟机都会报"设备不匹配"。

### 4.4 运行主程序

```
".venv\Scripts\python.exe" main.py
```

`main.py` 无需任何参数，启动后会依次完成九节：

1. **数据加载与解密**：加载 12 层 GeoTIFF、统一裁剪到最小公共尺寸；逐个解密 8 个 `.enc` 文件
2. **AHP 易发性评估**：按 `config.json` 的 `ahp_weights` 加权叠加 10 因子，分 5 级风险
3. **降雨监测分析**：统计站点 TOP10、按小时聚合、找最大降雨事件
4. **分级预警模拟**：按蓝/黄/橙/红阈值（15/30/50/70 mm·1h）统计触发频率
5. **人口与避难所分析**：总人口、区县分布、避难场所类型与容量
6. **转移路线规划**：识别高风险聚落，匹配最近低风险避难所，估算步行时间
7. **救援力量调度**：5 类救援力量（专业救援队/消防/武警/医疗/志愿者）配置
8. **数据导出**：导出 `grid_data.csv` 与 5 个 JSON
9. **可视化出图**：生成 6 张 PNG

### 4.5 命令汇总

| 步骤 | 命令 | 执行目录 |
|---|---|---|
| 生成授权 | `python keygen.py` | `源码/` |
| 运行主程序 | `python main.py` | `源码/` |

## 六、遇到问题怎么办

### 报错对照表

| 报错信息 | 原因 | 解决方案 |
|---|---|---|
| `'python' 不是内部或外部命令` | Python 未安装或未加入 PATH | 重新安装 Python，务必勾选 "Add Python to PATH" |
| `ModuleNotFoundError: No module named 'rasterio'` | rasterio 未装上 | 见 6.5 节，改用 conda 方式安装 |
| `[License] Error: .license 文件不存在` | 没生成授权 | 回到 `源码/` 运行 `python keygen.py`，或直接重跑一键脚本 |
| `[License] Error: 授权已失效` / `授权已用完` | license 是单次授权，上次跑主程序时消费掉了 | 重新运行 `python keygen.py` 生成新授权，再跑 `main.py` |
| `[License] Error: 授权与当前设备不匹配` | license 绑定了别的电脑/虚拟机 | 必须在**运行 main.py 的同一台电脑**上跑 keygen.py |
| `[License] Error: 授权签名无效` | `.license` 被手动改过 | 删除 `.license`，重新跑 `keygen.py` |
| 解密 `json.loads` 报错 / `UnicodeDecodeError` | `.enc` 文件被改动或密钥还原错误 | 切勿手动编辑 `.enc`；从原始备份恢复数据 |
| `FileNotFoundError: ... processed_data\*.tif` | 路径不对 | 检查 `config.json` 的 `paths` 是否指向真实目录（见 6.6） |
| `PermissionError` | 文件被占用 | 关闭 Excel/图片查看器等正在打开结果文件的程序，重新运行 |
| 窗口一闪就关了 | 运行出错但没看到信息 | 在 cmd 里手动 `cd` 进 `源码/`，手动跑 `一键运行.bat` 看报错 |
| 图里中文显示成方块 | 系统缺 SimHei/微软雅黑字体 | Windows 一般自带；Linux 需装 `fonts-wqy-zenhei` 或改 `config.json` 的 `fonts` |

### 6.1 我可以不用命令行吗？

可以。双击 `一键运行.bat` 即可，不需要手动输入任何命令。

### 6.2 第二次运行还需要重新安装吗？

不需要。虚拟环境和依赖只安装一次，之后每次运行会直接跳到授权和主程序步骤。但**每次跑主程序前都要重新生成 license**（单次授权），一键脚本会自动帮你做这步。

### 6.3 为什么授权总是"用完"？

这是项目自研机制设计的：`.license` 字段 `max_uses: 1`，跑一次 `main.py` 就把 `use_count` 加到上限并置 `valid=False`。这是为了演示"设备绑定 + 单次授权"的安全模型。**对策很简单：每次运行前重新跑一次 `keygen.py`**（一键脚本已自动处理）。

### 6.4 能不能在虚拟机/容器里运行？

**不建议**。license 绑定设备指纹（`SHA-256(MAC地址 + 主机名)`）。在虚拟机里生成 license、再换到宿主机运行会报"设备不匹配"。请在**最终运行 `main.py` 的同一台物理机**上执行 `keygen.py`。

### 6.5 rasterio 装不上怎么办（最重要！）

`rasterio` 依赖 GDAL 地理库，Windows 下 `pip install rasterio` 偶尔会因为缺少 GDAL 编译环境而失败。**首选 conda 方式**（成功率最高）：

**方式 A：用 conda（推荐，成功率最高）**

如果还没装 conda，先装 Miniconda（轻量）：https://docs.conda.io/en/latest/miniconda.html

装好后，打开 **Anaconda Prompt**（不是普通 cmd），执行：

```
conda create -n debris-flow python=3.10 -y
conda activate debris-flow

REM 用 conda 装 GDAL + rasterio + numpy + matplotlib（带预编译二进制，不编译）
conda install -c conda-forge gdal rasterio numpy=2.2.6 matplotlib=3.10.9 -y

REM 剩下两个用 pip 装
pip install pycryptodome==3.23.0 psycopg2-binary==2.9.12
```

然后进入源码目录跑授权和主程序（注意用 conda 环境的 python，不是 .venv）：

```
cd /d D:\你的路径\18组_AI辅助山区泥石流零死亡方案\源码
python keygen.py
python main.py
```

> 用了 conda 环境就**不要再用 `.venv`**，二选一即可。conda 环境里 `python` 直接就是你要用的解释器。

**方式 B：用 pip（先试这个，多数情况能成）**

```
".venv\Scripts\python.exe" -m pip install rasterio==1.4.4
```

rasterio 官方在 PyPI 提供了 Windows 预编译 wheel（自带 GDAL），**Python 3.10~3.12 + 64 位**通常能直接装上。如果失败：

- 换国内镜像重试：`-i https://pypi.tuna.tsinghua.edu.cn/simple`
- 确认是 64 位 Python（32 位没有预编译包）
- 确认 Python 版本是 3.10~3.12
- 实在不行就走方式 A（conda）

### 6.6 路径找不到数据 / 移动过项目文件夹

`源码/config.json` 的 `paths` 字段填的是**绝对路径**。当前已指向项目实际位置。如果你**移动或重命名了项目文件夹**，必须同步修改 `config.json` 里这四个路径：

```json
{
  "paths": {
    "base": "D:/你的新路径/18组_AI辅助山区泥石流零死亡方案",
    "raster_dir": "D:/你的新路径/18组_AI辅助山区泥石流零死亡方案/数据集/processed_data",
    "vector_dir": "D:/你的新路径/18组_AI辅助山区泥石流零死亡方案/数据集/database_data",
    "output_dir": "D:/你的新路径/18组_AI辅助山区泥石流零死亡方案/源码/output"
  }
}
```

> 路径分隔符用 `/` 或 `\\` 都行。用记事本打开 `config.json` 编辑即可，注意别破坏 JSON 格式（逗号、引号别漏）。
>
> 不填这几个字段会怎样？`main.py` 会回退到默认拼接逻辑，而默认逻辑硬编码了旧目录名（`1_数据包` / `2_源码`），和现在的 `数据集` / `源码` 对不上，会找不到数据。所以**务必保持 config.json 路径正确**。

### 6.7 中文乱码

项目路径含中文，`main.py` 顶部已 `sys.stdout.reconfigure(encoding='utf-8')`。一键脚本开头也做了 `chcp 65001`。若仍有乱码，在 cmd 里先执行 `chcp 65001` 再运行。

### 6.8 解密相关的红线

- **不要**手动打开、编辑、另存 `.enc` 文件（用记事本/Excel 另存会破坏二进制结构导致解密失败）
- **不要**把别的电脑生成的 `.license` 拷过来用（设备不匹配）
- `.license` 是明文 JSON 但含签名，**不要**手动改里面的字段（会触发签名校验失败）

### 核心机制

- **AHP 易发性评估**：10 因子加权叠加，权重见 `config.json` 的 `ahp_weights`（坡度 0.25 最高，pH 0.02 最低，和为 1.00）。部分因子反向标准化（高程/NDVI/有机碳越高易发性越低），pH 用非线性。
- **风险分级**：按 `risk_thresholds: [0.2, 0.4, 0.6, 0.8]` 分 5 级。
- **分级预警**：依据国标 GB/T 28592-2012、QX/T 487-2019，蓝/黄/橙/红阈值（1h：15/30/50/70 mm）。
- **救援力量**：5 类（专业救援队 2×50、消防 3×30、武警 2×100、医疗 4×20、志愿者 5×15 人）。
- **加密授权**：AES 密钥的原始材料仅存于 `keygen.py` 源码；用设备指纹（前 16 字节）XOR 加密后写入 `.license` 的 `enc_key` 字段，并用 HMAC-SHA256 签名；`main.py` 启动时校验签名→校验设备→还原 AES 密钥→消费授权→解密 `.enc`。
