## 四、核心源码与脚本

### 1. GraphRAG 核心代码

`graphrag_atlas` 是本项目的图谱构建核心模块，承担从文本到知识图谱的主要计算工作：

| 文件 | 作用 |
|---|---|
| `graphrag_atlas/pipeline.py` | 主流程，负责语料读取、分块、抽取、索引和结果落盘。 |
| `graphrag_atlas/extractor.py` | 规则抽取器，面向地震灾害技术实体、任务、场景等进行结构化抽取。 |
| `graphrag_atlas/llm_extractor.py` | LLM 抽取器，支持通过大模型增强实体关系抽取。 |
| `graphrag_atlas/community.py` | 社区发现与社区报告生成逻辑。 |
| `graphrag_atlas/search.py` | 本地查询、全局查询和技术缺口查询相关逻辑。 |
| `graphrag_atlas/models.py` | 文档、实体、关系、声明等数据结构定义。 |
| `graphrag_atlas/io_utils.py` | JSONL/CSV/文件读写工具。 |
| `graphrag_atlas/__main__.py` | 命令行入口。 |
