# 地震灾害AI关键技术图谱项目阶段性工作汇总

更新时间：2026-06-18

## 1. 项目定位

本项目已从泛化的防灾减灾技术展示，收敛为“以地震灾害为例”的 GraphRAG 风格工程项目。当前目标是围绕以下流程构建地震灾害AI关键技术图谱：

```text
地震专题语料
  -> GraphRAG 抽取实体、关系、声明、证据来源
  -> 构建地震关键技术社区和 community reports
  -> 面向问题检索与归纳
  -> 发现地震早期预警、震后损毁评估、应急调度、生命线风险和证据链问答等技术簇
  -> 专家校验
  -> 沉淀为地震灾害AI关键技术图谱
```

## 2. 已完成的工程结构

```text
graphrag_atlas/
  __main__.py          # CLI入口
  models.py            # Document / Chunk / Entity / Claim / Relation / CommunityReport
  io_utils.py          # Markdown语料读取、frontmatter解析、chunk切分、JSONL输出
```

## 6. 查询能力

已实现三类查询：

```bash
npm.cmd run atlas:global
npm.cmd run atlas:local
npm.cmd run atlas:gaps
```

也可以直接使用中文查询：

```bash
python -m graphrag_atlas global-search "地震灾害AI防灾减灾有哪些关键技术社区" --output outputs/graphrag_index
python -m graphrag_atlas local-search "遥感震损智能解译" --output outputs/graphrag_index
python -m graphrag_atlas gap-search --output outputs/graphrag_index
```

`gap-search` 当前用于检查技术节点是否缺少：

```text
案例验证关系 VALIDATED_IN
数据依赖关系 DEPENDS_ON
技术限制关系 LIMITED_BY
```

## 7. LLM抽取接入

已新增 LLM 抽取器，支持三种模式：

```text
rule   = 本地规则抽取，不需要API key
llm    = 严格LLM抽取，缺少API key会报错
hybrid = 规则抽取 + LLM抽取；LLM失败时保留规则结果
```

命令：

```bash
npm.cmd run atlas:index
npm.cmd run atlas:index:llm
npm.cmd run atlas:index:hybrid
```

LLM 接口采用 OpenAI-compatible `/chat/completions` 形式。模型输出被限制在 `config/ontology.json` 的实体 ID 和关系规则内。
