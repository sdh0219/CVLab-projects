# Humanitarian mapping for earthquake response

该项目来源为“Humanitarian mapping for earthquake response”，来源机构或平台为 Humanitarian OpenStreetMap Team。在地震灾害AI防灾减灾关键技术图谱中，该来源被整理为 地震 专题证据，主要支撑 地震多模态灾情理解 技术社区，并服务 震前监测感知 场景。

从可抽取证据看，地震多模态灾情理解 依赖 众源文本，常结合 Transformer，用于完成 灾情态势摘要。该证据可与 阿富汗地震 形成案例验证关系，并受 数据共享与隐私合规 的治理要求约束。

面向 GraphRAG 索引，可形成“地震多模态灾情理解 -> 地震 -> 震前监测感知 -> 灾情态势摘要 -> 众源文本 -> Transformer -> 阿富汗地震”的证据链。该来源同时提示需要关注 数据偏差、专家校验和证据可追溯性。

元数据层面，该证据的区域为 global，年份为 2024。本整理稿只保留用于实体、关系和声明抽取的中文摘要，不替代原文引用。
