# QD02 · GraphRAG 驱动的地震灾害 AI 关键技术图谱 · 零基础复现与使用指南

> 本指南面向零基础同学。跟着"复现手册"一步步做，就能把项目跑起来；再看"用户使用手册"理解它是什么、怎么用。

# 第一部分 · 复现手册

## 1.1 你需要准备什么

| 需要的东西 | 说明 |
|---|---|
| Windows 电脑 | Windows 10/11，64 位 |
| Python 3.10+ | 运行后端代码（安装见 1.2） |
| Node.js 18+ | 运行网页前端（安装见 1.3） |
| VS Code | 推荐编辑器，安装见 1.4 |

本项目分两部分：
- **后端**（Python）：读取语料 → 抽取实体关系 → 构建图谱数据
- **前端**（Node.js + Next.js）：把图谱数据渲染成可交互网页

## 1.2 安装 Python

1. 访问 **https://www.python.org/downloads/** ，点黄色 **Download Python 3.x.x**
2. 双击安装包，**务必勾选 "Add python.exe to PATH"**，点 Install Now
3. 验证：`Win + R` → 输入 `cmd` 回车 → 输入 `python --version`，看到版本号即成功

## 1.3 安装 Node.js

1. 访问 **https://nodejs.org/zh-cn/download** ，下载 **Windows 安装包（LTS 版）**
2. 双击安装，一路下一步（默认选项即可）
3. 验证：命令行输入 `node --version`，看到 `v18.x` 或更高版本即成功

## 1.4 安装 VS Code

访问 **https://code.visualstudio.com/** ，下载安装即可（可选，但强烈推荐）。

## 1.5 下载本项目

项目目录结构：

```
QD02组_GraphRAG驱动的地震灾害AI关键技术图谱/
├── 源码/
│   ├── main.py              ← 图谱构建主程序
│   ├── requirements.txt     ← Python 依赖清单
│   ├── code/                ← 后端核心代码（graphrag_atlas 等）
│   └── 前端页面/             ← Next.js 网页前端
├── 数据集/
│   └── 1_数据包/             ← 49 篇地震文献语料 + 图谱快照数据
└── 文档/                    ← 技术方案与汇报材料
```

把整个文件夹放到电脑上，例如 `D:\projects\QD02组_...`。

## 1.6 安装后端依赖

1. 打开 `源码` 文件夹，地址栏输入 `cmd` 回车
2. 创建并激活虚拟环境：

```
python -m venv venv
venv\Scripts\activate
```

3. 安装依赖：

```
pip install -r requirements.txt
```

## 1.7 构建知识图谱（运行主程序）

执行：

```
python main.py
```

程序会自动读取 `数据集/1_数据包/` 中的语料，抽取实体、关系、声明，生成社区报告和图谱文件。

**预期产物**（在 `源码/code/outputs/` 或类似目录下）：
- 实体与关系表（CSV）
- 社区报告（community_reports）
- 图谱导出文件（GraphML / JSON，可用 Neo4j 或浏览器打开）
- 质量报告与问答评测结果

看到"图谱构建完成"之类的输出即成功。

## 1.8 启动网页前端

1. 进入前端目录：

```
cd "前端页面"
```

2. 安装前端依赖（需要几分钟，Node 会自动下载）：

```
npm install
```

3. 启动开发服务器：

```
npm run dev
```

4. 浏览器访问 **http://localhost:3000**，看到地震关键技术图谱页面即成功

> 如果 3000 端口被占用，终端会提示换端口（如 3001），用提示的地址访问即可。

## 1.9 复现完成

跑通 1.7（后端构建）和 1.8（前端网页），项目复现完成。下面看使用手册。

# 第二部分 · 用户使用手册

## 2.1 这个项目是做什么的

地震防灾减灾领域有海量文献（论文、专利、政策、案例、标准……），但**知识是散的**：你想知道"地震早期预警"有哪些关键技术、谁在做、用到什么方法，得自己翻几十篇文献。

GraphRAG（图检索增强生成）的思路是：先把文献**结构化**——抽出里面的"实体"（技术、机构、算法）、"关系"（谁提出了什么、用于什么场景），连成一张**知识图谱**，再按社区聚类，回答"关键技术簇"这类问题。

```
49 篇地震文献（论文/专利/政策/案例/标准/报告/项目）
        │  GraphRAG 管线：实体抽取、关系抽取、声明抽取
        ▼
   实体-关系图谱（CSV / JSON / GraphML）
        │  社区发现 + 社区报告
        ▼
   地震关键技术簇（早期预警 / 震损评估 / 应急调度 / 生命线风险 / 证据链问答）
        │
        ▼
   网页可视化（前端）+ 检索问答（Global/Local/Gap Search）
```

## 2.2 输入与输出

**输入**：`数据集/1_数据包/` 中的地震专题语料
- 7 类文献 × 每类 7 篇 = **49 篇**（论文、专利、政策、案例、标准、报告、项目）
- 每篇包含来源、时间、区域、技术主线等元信息

**输出**：
| 输出 | 格式 | 说明 |
|---|---|---|
| 实体/关系/声明表 | CSV / JSON | 图谱的原始数据 |
| 社区报告 | Markdown | 每个关键技术簇的总结 |
| 图谱文件 | GraphML / JSON | 可导入 Neo4j 或可视化工具 |
| 前端网页 | http://localhost:3000 | 交互式图谱浏览 |
| 问答评测 | JSON | 检索效果评估 |

## 2.3 网页功能说明（前端页面）

| 功能 | 操作 | 说明 |
|---|---|---|
| 图谱总览 | 打开首页 | 地震关键技术簇的节点与关系网络 |
| 节点详情 | 点击图谱中的节点 | 查看该技术/文献的详细信息 |
| 本地检索 Local Search | 搜索框输入问题 | 针对某节点/社区的问题检索 |
| 全局检索 Global Search | 切换到全局模式 | 跨社区综合检索 |
| 差距检索 Gap Search | 选择"Gap"模式 | 发现尚未覆盖的技术空白 |

## 2.4 命令行功能（后端，可选）

在 `源码` 目录（venv 激活）下可以运行更多工具：

| 命令（示例） | 作用 |
|---|---|
| `python main.py` | 完整构建图谱 |
| `python -m code.tools.xxx` | 各工具模块（导出、评测、导入 Neo4j 等，见 code/tools/） |

具体命令以 `code/tools/` 目录下的模块说明为准。

## 2.5 常见问题

| 问题 | 原因与解决 |
|---|---|
| `npm` 不是内部或外部命令 | Node.js 没装好，重装后重启命令行 |
| 前端页面白屏/报错 | 确认 `npm install` 成功完成、`npm run dev` 没报错 |
| 图谱数据为空 | 确认已先运行 1.7 构建主程序（前端读取其输出） |
| 端口占用 | 前端换端口：`npm run dev -- -p 3001` |
