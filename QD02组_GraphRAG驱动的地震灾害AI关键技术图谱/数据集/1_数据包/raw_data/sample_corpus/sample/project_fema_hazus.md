# Hazus earthquake loss estimation program

该项目来源为“Hazus earthquake loss estimation program”，来源机构或平台为 FEMA。在地震灾害AI防灾减灾关键技术图谱中，该来源被整理为 地震 专题证据，主要支撑 震后灾情快速评估 技术社区，并服务 震后损毁评估 场景。

从可抽取证据看，震后灾情快速评估 依赖 遥感影像，常结合 Transformer，用于完成 灾情态势摘要。该证据可与 土耳其叙利亚地震 形成案例验证关系，并受 地震应急预案 的治理要求约束。

面向 GraphRAG 索引，可形成“震后灾情快速评估 -> 地震 -> 震后损毁评估 -> 灾情态势摘要 -> 遥感影像 -> Transformer -> 土耳其叙利亚地震”的证据链。该来源同时提示需要关注 实时部署困难、专家校验和证据可追溯性。
