# CVLab-projects · 袁静课题组可复现项目集

袁静课题组（Yuan Lab）应急管理计算机视觉方向的可复现教学项目集，面向培训班零基础学员。共 **20 个项目**：**基础上机（初阶）9 个**（目录 `基础上机（初阶）/`）+ **基础上机（中阶）11 个**（根目录 QD 各组）。每个项目配套《README.md》或《复现指南》（复现手册 + 用户使用手册），按指南逐步操作即可完成复现与使用。

## 统一环境要求（开课前确认）

- **Python 3.10 – 3.12（64 位）**：初阶项目代码使用了 `str | Path` 等新语法，3.9 及以下直接报错；QD12/QD15/QD18 不支持 3.13+ 和 32 位
- **每个项目独立 venv**（各组依赖版本不同，禁止共用环境）
- **联网需求**：所有项目 `pip install` 需联网；装好后仅 QD12 必须联网下载 BERT 权重（约 411MB，可用 U 盘预分发替代，见其指南 2.1）、QD02/QD15 前端需 `npm install`，其余全部离线可跑
- **Node.js**：仅 QD02（≥ 22.13）和 QD15（≥ 20.19）需要
- 易错点速查（QD05 需把 `数据集` 改名为 `data`、QD18 每次先跑 `keygen.py` 等）见各指南

## 使用方式

**新同学请先读 [学习必读.md](学习必读.md)**——它教你怎么用这套指南（对成功标志、查版本、读报错、正确提问），并给出项目的建议学习顺序。

中阶每个项目目录下包含三样东西：

- `源码/` — 完整源代码（含依赖清单 requirements.txt）
- `数据集/` — 项目数据
- `复现指南.md` — **零基础复现与学习指南**，分四部分：项目导览 → 复现手册 → 理解手册 → 附录。先读导览看懂项目是什么，再照复现手册一步步跑起来，最后用理解手册学透技术点（代码精讲 + 动手练习 + 报错速查）。

初阶项目结构更简单（源码 + `data/` + `README.md` + 一键 bat），进入项目目录打开 `README.md` 照做即可。

## 教学数据说明

本项目集的定位是**教学**：学生跑通流程、理解方法即可，不要求使用完整真实数据。部分项目采用"真实核心 + 合成/模拟补充"的数据策略，均在各自指南中说清楚（如 QD01 的 4 类 GeoJSON 为模拟替代、QD03 数据自生成、QD14 四川场景 `edges.csv` 为基于真实节点与真实灾害映射的合成重建版）。

## 项目筛选说明

中阶从 18 个结课项目中按以下标准筛选入库：
- 数据集过大（单文件超过 GitHub 100MB 限制 / 体积达 GB 级）的项目不入库（如 QD04/06/07/10/11）
- 依赖外部 Release 才能复现的项目不入库（如 QD16）
- 其余项目保留可复现的最小完整集合（源码 + 数据集 + 复现指南）
